⚡ Projet — Mon site interactif JavaScript

Reprends ton site HTML avancé et ajoute 3 features JavaScript DOM : pop-up, carrousel et notification.

JavaScript DOM Événements HTML avancé Interactions
🎯
Objectif du projet

Ce projet est la suite directe du projet HTML avancé. Tu repars du même site — et tu y ajoutes 3 features JavaScript qui rendent la page réellement interactive pour l'utilisateur.

L'objectif n'est pas de faire un site parfait — c'est de comprendre comment JavaScript interagit avec le DOM : sélectionner des éléments, écouter des événements, modifier l'affichage en réponse à une action utilisateur.

⚠️ Tout ton JavaScript doit être dans un fichier script.js séparé, lié en bas du <body> avec <script src="script.js"></script>. Pas de JS inline dans le HTML.
⚡
Les 3 features à implémenter

Tu dois ajouter exactement ces 3 interactions. Chacune utilise des concepts DOM différents :

🪟 Pop-up / Modal
Un bouton ouvre une fenêtre modale. Un bouton "Fermer" ou un clic hors de la modale la referme.
🖼️ Carrousel / Galerie
Des boutons "Précédent" et "Suivant" font défiler des images ou des cartes de contenu.
🔔 Notification / Toast
Un message apparaît en bas ou en haut de l'écran après une action (clic, envoi de formulaire…) et disparaît automatiquement après 3 secondes.
// Exemple — ouvrir une modale
const btn = document.querySelector('#open-modal');
const modal = document.querySelector('#modal');
btn.addEventListener('click', () => {
  modal.style.display = 'flex';
});
🧠 Pour la notification : utilise setTimeout(() => { ... }, 3000) pour la faire disparaître automatiquement après 3 secondes.
📋
Cahier des charges — Exigences obligatoires
✅ Tout le JavaScript est dans un fichier script.js séparé, lié en bas du <body>.
✅ Pop-up / Modal : un bouton l'ouvre, un bouton "Fermer" la referme. La modale est masquée par défaut (display: none).
✅ Carrousel : au moins 3 éléments (images ou cartes), boutons Précédent/Suivant fonctionnels, retour au début après le dernier élément.
✅ Notification : apparaît après une action spécifique, disparaît automatiquement après 3 secondes avec setTimeout.
✅ Aucun alert() utilisé — tout se passe dans la page via le DOM.
✅ Le site reste visuellement cohérent avec le projet HTML avancé — le CSS existant est conservé.
⭐
Points bonus
🌟 Fermer la modale en cliquant sur le fond sombre derrière elle (écouter le clic sur l'overlay).
🌟 Ajouter des points de navigation au carrousel (• • •) qui indiquent l'élément actif.
🌟 La notification a une animation CSS d'entrée et de sortie (transition ou animation).
🌟 Ajouter une 4e feature : dark mode toggle, compteur de clics, filtrage de contenu par catégorie…
🚀
Comment réaliser ce projet
1
Reprends ton dossier HTML avancé. Crée script.js et lie-le en bas du <body>. Vérifie que console.log('JS chargé') s'affiche bien dans la console.
2
Commence par la pop-up — c'est la plus simple. Ajoute le HTML de la modale (masquée par défaut), puis en JS : sélectionne le bouton, ajoute un addEventListener('click', ...).
3
Implémente le carrousel. Crée un tableau d'éléments en JS, une variable index = 0, et deux fonctions prev() et next() qui modifient l'affichage.
4
Ajoute la notification. Crée une <div> de notification masquée dans le HTML. En JS, une fonction showNotif(message) l'affiche et appelle setTimeout pour la masquer.
5
Teste chaque feature dans le navigateur, ouvre la console (F12) pour déboguer. Assure-toi que les 3 fonctionnent sans erreur.
