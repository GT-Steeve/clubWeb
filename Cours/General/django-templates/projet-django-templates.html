</> Templates HTML Django

Suite de vibecoding-django — construire un vrai système de templates avec héritage et affichage de données.

Suite de vibecoding-django DTL 7 étapes ~35 min base.html + données
🎯
Objectif du projet

Tu repars du projet avec la page /blog/ fonctionnelle. Cette fois tu vas structurer un vrai système de templates : un base.html parent, des templates enfants avec {% extends %}, et surtout afficher de vraies données transmises depuis la vue via le contexte.

💡Le principe clé du cours — La vue prépare les données dans un dictionnaire de contexte, le template les affiche avec {{ variable }}. Ce mécanisme est au cœur de tout projet Django.
Progression 0 / 7 étapes
1
Créer le template parent base.html
Le squelette HTML commun à toutes les pages du blog.
✓

Remplace le contenu de blog/templates/blog/base.html par ce squelette complet avec les blocs Django :

blog/templates/blog/base.html 
{% load static %}
<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <title>{% block title %}Mon Blog{% endblock %}</title>
  <link rel="stylesheet" href="{% static 'blog/css/style.css' %}">
</head>
<body>
  <nav>
    <a href="{% url 'blog:index' %}">Accueil</a>
  </nav>

  <main>
    {% block content %}
    {% endblock %}
  </main>
</body>
</html>
🔑Les blocs {% block %} sont les zones que les templates enfants vont remplacer. title pour le titre de l'onglet, content pour le contenu de la page. Tout le reste (nav, CSS) est partagé automatiquement.
2
Faire hériter index.html de base.html
{% extends %} — le template enfant hérite de la structure parente.
✓

Remplace le contenu de blog/templates/blog/index.html par cette version qui hérite de base.html :

blog/templates/blog/index.html 
{% extends 'blog/base.html' %}

{% block title %}Accueil — Mon Blog{% endblock %}

{% block content %}
  <h1>Bienvenue sur le Blog</h1>
  <p>{{ message }}</p>
{% endblock %}
💡{% extends %} doit être la toute première ligne du fichier. Si ce n'est pas le cas, Django lève une erreur. Il ne peut y avoir qu'un seul extends par template.
⚠️{{ message }} est une variable — elle sera remplie par le contexte que la vue envoie. Si la vue n'envoie pas message, Django affiche simplement rien (pas d'erreur).
3
Passer des données depuis la vue
Le dictionnaire de contexte — le pont entre views.py et le template.
✓

Mets à jour la view index dans blog/views.py pour envoyer des données au template via le contexte :

blog/views.py 
from django.shortcuts import render

def index(request):
    contexte = {
        'message': 'Bienvenue sur mon blog Django !',
        'articles': [
            {'titre': 'Mon premier article', 'auteur': 'Alice'},
            {'titre': 'Apprendre Django',    'auteur': 'Bob'},
            {'titre': 'Les templates DTL',   'auteur': 'Alice'},
        ]
    }
    return render(request, 'blog/index.html', contexte)
📌On utilise une liste de dictionnaires Python pour simuler des articles — pas encore de base de données. C'est suffisant pour apprendre à afficher des données dans les templates.
4
Afficher la liste d'articles avec {% for %}
Variables, boucles et filtres DTL en pratique.
✓

Mets à jour blog/templates/blog/index.html pour afficher la liste des articles passés par la vue :

blog/templates/blog/index.html — version complète 
{% extends 'blog/base.html' %}

{% block title %}Accueil — Mon Blog{% endblock %}

{% block content %}
  <h1>{{ message }}</h1>

  {% if articles %}
    <ul>
      {% for article in articles %}
        <li>
          <strong>{{ article.titre }}</strong>
          — par {{ article.auteur|title }}
        </li>
      {% endfor %}
    </ul>
  {% else %}
    <p>Aucun article pour l'instant.</p>
  {% endif %}

  <p>{{ articles|length }} article(s) au total.</p>
{% endblock %}
🎯Trois éléments du DTL en une seule page : {{ variable }} pour afficher, {% if/for %} pour la logique, |title et |length pour les filtres. Ce sont les outils les plus courants de tout projet Django.
5
Créer une page about.html
Un deuxième template enfant pour valider l'héritage.
✓

Crée le fichier blog/templates/blog/about.html :

blog/templates/blog/about.html 
{% extends 'blog/base.html' %}

{% block title %}À propos — Mon Blog{% endblock %}

{% block content %}
  <h1>À propos</h1>
  <p>Ce blog est fait avec Django {{ django_version }}.</p>
{% endblock %}

Ajoute la view et la route correspondantes :

blog/views.py — ajouter 
import django

def about(request):
    return render(request, 'blog/about.html', {
        'django_version': django.get_version()
    })
blog/urls.py — ajouter 
path('about/', views.about, name='about'),

Puis ajoute le lien dans la navigation de base.html :

blog/templates/blog/base.html — nav 
<nav>
  <a href="{% url 'blog:index' %}">Accueil</a>
  <a href="{% url 'blog:about' %}">À propos</a>
</nav>
💡{% url 'blog:about' %} génère l'URL dynamiquement. Si tu changes le chemin dans urls.py, tous les liens se mettent à jour automatiquement — jamais d'URL en dur dans les templates.
