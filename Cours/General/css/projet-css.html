🎨 Projet — Mon site stylisé en CSS

Reprends ta page HTML et transforme-la visuellement — mise en page, typographie, espace, couleurs.

HTML CSS complet Flexbox / Grid Typographie Responsive
🎯
Objectif du projet

Ce projet est la suite directe du projet HTML. Tu repars du même fichier index.html que tu as déjà créé — et tu y ajoutes un fichier CSS séparé (style.css) pour lui donner du style.

L'objectif : transformer une page fonctionnelle mais brute en une page visuellement agréable, bien organisée et lisible. Tu dois travailler la mise en page avec Flexbox ou Grid, la typographie, les espacements et les couleurs.

💡 Le CSS va dans un fichier séparé style.css lié dans le <head> : <link rel="stylesheet" href="style.css">. Plus de CSS dans le HTML — sauf exception justifiée.
📚
Ce que tu vas mettre en pratique

Tu vas utiliser les 6 grands domaines du CSS pour habiller ta page :

📦 Box model
margin, padding, border, width — l'espace autour et à l'intérieur.
🔤 Typographie
font-family, font-size, font-weight, line-height, text-align.
🎨 Couleurs
color, background-color, border-color — avec une palette cohérente.
🏗️ Flexbox / Grid
Mise en page de sections, centrage, colonnes — display: flex ou grid.
✨ Effets
border-radius, box-shadow, transition — le côté soigné et moderne.
📱 Responsive
@media — la page s'adapte sur mobile avec quelques règles simples.
📋
Cahier des charges — Exigences obligatoires
✅ Un fichier style.css séparé, lié correctement au HTML avec <link>.
✅ Le <header> est visuellement distinct : couleur de fond, centrage du texte, padding généreux.
✅ Une mise en page avec Flexbox ou Grid pour au moins une section (ex : cards côte à côte, deux colonnes…).
✅ La typographie est soignée : police lisible, taille cohérente entre h1, h2, p, espacements.
✅ Les liens (<a>) ont un style au survol (:hover) différent de l'état normal.
✅ Le <footer> est visuellement distinct du contenu principal.
✅ La largeur de la page est limitée (ex : max-width: 900px; margin: 0 auto;) — le texte ne s'étire pas sur tout l'écran.
⭐
Points bonus
🌟 Utiliser des variables CSS (:root { --couleur: #3C3489; }) pour centraliser toute la palette de couleurs.
🌟 Ajouter une @media query pour que la page soit lisible sur mobile (colonnes → 1 colonne, texte plus petit…).
🌟 Ajouter des transitions CSS sur les liens ou les cards (transition: 0.2s ease).
🌟 Styliser les listes : supprimer les puces par défaut, ajouter une icône ou un style personnalisé.
🌟 Utiliser une Google Font importée dans le <head> pour une typographie personnalisée.
🚀
Comment réaliser ce projet
1
Reprends ton dossier HTML du projet précédent. Crée un fichier style.css dans le même dossier et lie-le dans le <head>.
2
Commence par le body : police, couleur de fond, max-width, margin: 0 auto. C'est la base de tout le reste.
3
Style le header en premier — couleur de fond, padding, centrage. Il donne le ton visuel de toute la page.
4
Travaille section par section. Pour chaque partie du contenu : espacements, couleurs, éventuellement une mise en page Flexbox.
5
Ajoute les effets : border-radius sur les images, box-shadow sur les cards, :hover sur les liens.
6
Vérifie sur un écran plus petit (DevTools → mode responsive) et ajuste si nécessaire avec une @media.
