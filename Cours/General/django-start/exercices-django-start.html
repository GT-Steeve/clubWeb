views.py↻
Logique de chaque page — reçoit une requête, retourne une réponse
urls.py↻
Fait le lien entre une URL et la vue qui doit répondre
makemigrations↻
Crée un fichier de migration à partir des modifications de models.py

Dans le urls.py du projet — délègue les routes à l'urls.py d'une app

04 — Scénarios — que faites-vous ?
Scénario 1
🧑‍💻 Vous démarrez un nouveau projet Django sur votre Mac. Quelle est la première commande à lancer après avoir créé le dossier ?
pip install django directement
python -m venv env, activer l'environnement, puis pip install django
django-admin startproject monsite
✓ On crée et active TOUJOURS l'environnement virtuel avant d'installer quoi que ce soit. L'installation globale crée des conflits futurs.
Scénario 2
🧑‍💻 Vous ajoutez un champ slug à votre model. Vous relancez le serveur et obtenez : Table blog_article has no column named slug. Que faites-vous ?
Supprimer la base de données et tout recommencer
Vérifier que le champ est bien écrit dans models.py
Lancer python manage.py makemigrations puis python manage.py migrate
✓ La migration n'a pas été créée ni appliquée. La BDD ne connaît pas encore le nouveau champ. makemigrations + migrate est la solution.
Scénario 3
🧑‍💻 Votre page /blog/ retourne une erreur Page not found (404) alors que vous avez bien créé votre vue et votre blog/urls.py. Où cherchez-vous en premier ?
Dans views.py — vérifier le nom de la fonction
Dans monsite/urls.py — vérifier que include('blog.urls') est bien présent
Dans settings.py — vérifier que DEBUG est à True
✓ Un 404 sur une route signifie que Django ne trouve pas l'URL. Le routeur principal doit déléguer à l'app avec include(). C'est l'oubli n°1 des débutants.
Scénario 4
🧑‍💻 Vous partagez votre projet sur GitHub. Votre collègue clone le dépôt — le dossier env/ est absent et Django n'est pas installé. Comment réinstaller toutes les dépendances en une commande ?
pip install django — et réinstaller chaque paquet un par un
Créer un venv, l'activer, puis pip install -r requirements.txt
Copier son propre dossier env/ et l'envoyer par email
✓ C'est exactement l'utilité de requirements.txt — une seule commande suffit pour recréer l'environnement exact sur n'importe quelle machine.
