Construis un vrai jeu de plateforme en Canvas : un personnage qui saute, des plateformes, et des pièces à collecter.

Ce projet fait suite au projet Clicker. Tu connais déjà les variables, le DOM et addEventListener. On passe maintenant au Canvas 2D : une zone de dessin contrôlée entièrement par JavaScript, frame par frame. Le résultat : un vrai jeu de plateforme dans le navigateur.
Progression 0 / 7 étapes
1
HTML — La structure de base
▼

Crée un dossier platformer/ avec trois fichiers. Le canvas est la zone de jeu — toute la magie se passera dedans.

📁 platformer/ ├── index.html ← la structure ├── style.css ← l'apparence └── script.js ← le jeu
index.html
<!DOCTYPE html> <html lang="fr"> <head> <meta charset="UTF-8"> <title>Mon Platformer</title> <link rel="stylesheet" href="style.css"> </head> <body> <!-- HUD : affiche le nombre de pièces --> <div id="hud"> <span id="score-pieces">Pièces : 0 / 5</span> </div> <!-- La zone de jeu --> <canvas id="jeu" width="600" height="380"></canvas> <script src="script.js"></script> </body> </html>
💡
Le width et height du canvas définissent sa résolution interne, pas sa taille d'affichage CSS. Ne pas les oublier — sans eux le canvas fait 300×150 par défaut.
2

Un fond sombre, le canvas centré, et le HUD bien visible. Sobre et efficace.

3
Variables + clavier — Les fondations JS
▼

On initialise le canvas, les constantes physiques, l'objet joueur et la gestion du clavier. C'est le socle de tout le reste.

script.js — début du fichier
// Initialiser le canvas const canvas = document.getElementById('jeu'); const ctx = canvas.getContext('2d'); // Constantes physiques const GRAVITE = 0.5; // accélération vers le bas (px/frame²) const FORCE_SAUT = -12; // impulsion vers le haut (négatif = haut) // ← Change ce chiffre pour fixer l'objectif du niveau ! const NB_PIECES = 5; // L'objet joueur : position, vitesse, taille const joueur = { x: 40, y: 280, vx: 0, vy: 0, w: 32, h: 32, auSol: false }; let piecesRecuperees = 0; // Mémoriser les touches enfoncées (bonne approche !) const touches = {}; document.addEventListener('keydown', function(e) { touches[e.key] = true; // Empêcher la page de défiler avec les flèches if (['ArrowUp','ArrowDown','ArrowLeft','ArrowRight',' '].includes(e.key)) { e.preventDefault(); } }); document.addEventListener('keyup', function(e) { touches[e.key] = false; });
🎯
NB_PIECES détermine le nombre de pièces du niveau. Mets 3 pour un niveau facile, 10 pour un défi ! Le HUD et la condition de victoire s'adaptent automatiquement.
4
Plateformes — Le niveau
▼

Chaque plateforme est un objet simple {x, y, w, h}. On les met dans un tableau et on les dessine avec forEach. Tu peux en ajouter ou les repositionner librement.

script.js — ajouter après les variables
// Définir les plateformes (sol + plateformes en l'air) const plateformes = [ { x: 0, y: 340, w: 600, h: 40 }, // sol complet { x: 90, y: 270, w: 130, h: 15 }, { x: 290, y: 210, w: 130, h: 15 }, { x: 430, y: 275, w: 130, h: 15 }, { x: 170, y: 170, w: 100, h: 15 }, { x: 390, y: 155, w: 110, h: 15 }, ];
Dans la fonction draw() — dessiner les plateformes
function draw() { // Fond sombre ctx.fillStyle = '#0F172A'; ctx.fillRect(0, 0, canvas.width, canvas.height); // Plateformes plateformes.forEach(function(p) { ctx.fillStyle = '#374151'; ctx.fillRect(p.x, p.y, p.w, p.h); // Ligne verte sur le dessus pour effet herbe ctx.fillStyle = '#4B5563'; ctx.fillRect(p.x, p.y, p.w, 4); }); }
📐
Change librement les coordonnées des plateformes pour créer ton propre niveau ! Dessine-le d'abord sur papier : canvas = 600×380 px. x=0 est à gauche, y=0 en haut.
5
Joueur — Gravité, saut et collisions
▼

Le joueur commence comme un carré jaune. On ajoute la physique : gravité, déplacement horizontal, saut conditionné au sol, et atterrissage sur les plateformes.

script.js — fonctions update() et drawJoueur()
function update() { // Déplacements horizontaux if (touches['ArrowLeft']) joueur.vx = -4; else if (touches['ArrowRight']) joueur.vx = 4; else joueur.vx = 0; // Saut — seulement si les pieds touchent le sol if ((touches['ArrowUp'] || touches[' ']) && joueur.auSol) { joueur.vy = FORCE_SAUT; joueur.auSol = false; } // Physique : gravité + mouvement joueur.vy += GRAVITE; joueur.x += joueur.vx; joueur.y += joueur.vy; joueur.auSol = false; // sera mis à true si on atterrit // Limites gauche/droite if (joueur.x < 0) joueur.x = 0; if (joueur.x + joueur.w > canvas.width) joueur.x = canvas.width - joueur.w; // Atterrissage sur les plateformes plateformes.forEach(function(p) { if (joueur.x + joueur.w > p.x && joueur.x < p.x + p.w && joueur.y + joueur.h >= p.y && joueur.y + joueur.h <= p.y + 20 && joueur.vy >= 0) { joueur.y = p.y - joueur.h; joueur.vy = 0; joueur.auSol = true; } }); } // Dessiner le joueur — carré jaune avec des yeux function drawJoueur() { ctx.fillStyle = '#EAB308'; ctx.fillRect(joueur.x, joueur.y, joueur.w, joueur.h); ctx.fillStyle = '#1C1C1C'; ctx.fillRect(joueur.x + 7, joueur.y + 9, 6, 6); ctx.fillRect(joueur.x + 19, joueur.y + 9, 6, 6); }
🖼️ Variante — Utiliser une image PNG à la place
// Charger une image (ex: joueur.png dans le même dossier) const imgJoueur = new Image(); imgJoueur.src = 'joueur.png'; // Dans drawJoueur(), remplacer fillRect par : ctx.drawImage(imgJoueur, joueur.x, joueur.y, joueur.w, joueur.h);
6
Pièces — Générer, ramasser, victoire
▼

On génère NB_PIECES pièces réparties sur les plateformes. La collision AABB détecte quand le joueur en touche une. Quand tout est ramassé : écran de victoire !

script.js — ajouter après les plateformes
// Positions prédéfinies (sur les plateformes) const posPieces = [ { x: 140, y: 248 }, { x: 340, y: 188 }, { x: 462, y: 253 }, { x: 200, y: 148 }, { x: 420, y: 133 }, ]; let pieces = []; function genererPieces() { for (let i = 0; i < NB_PIECES; i++) { const pos = posPieces[i % posPieces.length]; pieces.push({ x: pos.x, y: pos.y, w: 20, h: 20, ramassee: false }); } } genererPieces();
La fonction collision (AABB)
function collision(a, b) { return a.x < b.x + b.w && a.x + a.w > b.x && a.y < b.y + b.h && a.y + a.h > b.y; }
Dans update() — ramasser les pièces
// À ajouter à la fin de update(), après les plateformes pieces.forEach(function(p) { if (!p.ramassee && collision(joueur, p)) { p.ramassee = true; piecesRecuperees++; document.getElementById('score-pieces').textContent = 'Pièces : ' + piecesRecuperees + ' / ' + NB_PIECES; } });
Dans draw() — dessiner les pièces + victoire
// Dessiner les pièces non ramassées pieces.forEach(function(p) { if (!p.ramassee) { ctx.fillStyle = '#FBBF24'; ctx.beginPath(); ctx.arc(p.x + 10, p.y + 10, 10, 0, Math.PI * 2); ctx.fill(); } }); // Écran de victoire if (piecesRecuperees >= NB_PIECES) { ctx.fillStyle = 'rgba(0,0,0,0.75)'; ctx.fillRect(0, 0, canvas.width, canvas.height); ctx.fillStyle = '#FBBF24'; ctx.font = 'bold 52px monospace'; ctx.textAlign = 'center'; ctx.fillText('🏆 VICTOIRE !', canvas.width / 2, canvas.height / 2 - 15); ctx.fillStyle = '#9CA3AF'; ctx.font = '20px monospace'; ctx.fillText('Toutes les pièces récupérées !', canvas.width / 2, canvas.height / 2 + 25); ctx.textAlign = 'left'; }

Game Loop — Assembler et lancer le jeu
▼

Particules quand on ramasse une pièce

Dans mon platformer Canvas JS, quand une pièce est ramassée (p.ramassee = true), ajoute un effet de particules dorées. J'ai un tableau pieces[] et une game loop avec update() et draw(). Montre-moi un tableau particles[], comment les générer à la position de la pièce, les faire monter/disparaître chaque frame et les dessiner dans draw().

Ennemi qui patrouille
Un bloc rouge qui fait des allers-retours sur une plateforme. Si le joueur le touche, retour au départ (ou perte d'une vie).
🤖 Prompt IA suggéré
Dans mon platformer, ajoute un ennemi qui patrouille sur une plateforme (x entre 290 et 420, y=195, w=32, h=32). Il doit faire des allers-retours en changeant de direction quand il atteint les bords. Si le joueur le touche (collision AABB), réinitialise sa position à x=40, y=280. Montre-moi l'objet ennemi, sa mise à jour dans update() et son dessin dans draw().

Arrière-plan avec étoiles
