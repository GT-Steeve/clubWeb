🌍 Projet — Ma note Web 1, 2 & 3

Crée ta note personnelle sur l'évolution du web — du web statique à la blockchain.

Note numérique Web 1 / 2 / 3 Blockchain Concepts clés
🎯
Objectif du projet

Tu vas créer ta note personnelle sur l'évolution du web. Ce n'est pas un résumé scolaire — c'est un document que tu gardes pour toi, rédigé dans tes propres mots, avec les concepts qui t'ont marqué.

Dans quelques semaines, si quelqu'un te demande la différence entre le Web 2 et le Web 3, tu dois pouvoir rouvrir ta note et répondre en 30 secondes.

💡Utilise tes propres analogies pour expliquer des concepts complexes comme la blockchain ou les NFT. Une bonne note, c'est celle que toi tu comprends rapidement — pas celle qui ressemble le plus au cours.
📚
Thèmes à couvrir

Ta note doit aborder ces 6 grandes notions du cours :

📖 Web 1
Le web statique, lecture seule. Pourquoi c'était limité.
👥 Web 2
Le web social et participatif. La centralisation et ses problèmes.
🔗 Web 3
La décentralisation, le principe de la blockchain.
₿ Bitcoin & Ethereum
La différence entre les deux, leur rôle respectif.
🖼️ NFT & DeFi
Ce que c'est, pourquoi ça fait débat.
💭 Mon avis
Ce que tu penses de l'évolution du web — avantages, limites, scepticisme.
📄
Format de ta note

Ta note peut prendre la forme qui te convient — l'essentiel est qu'elle soit numérique et consultable facilement.

Formats acceptés
🌐 Page HTML 📕 PDF 📘 Word / .docx 📝 Markdown .md
💡La page HTML reste le format recommandé. Mais si tu préfères Word ou un PDF bien structuré, c'est tout aussi valide.
📋
Exigences obligatoires
✅La note s'ouvre et est lisible sans erreur.
✅Elle couvre au moins 4 des 6 thèmes avec tes propres mots.
✅Elle est structurée : titre principal, sections séparées, contenu lisible d'un coup d'œil.
✅La différence entre Web 1, 2 et 3 est expliquée clairement — sans copier-coller du cours.
✅Au moins une section contient ton avis personnel sur ces évolutions.
⭐
Points bonus
🌟Créer une frise chronologique visuelle de l'évolution du web (en HTML/CSS ou dessinée).
🌟Ajouter des exemples concrets d'applications Web 2 (Instagram, Twitter…) vs Web 3 (OpenSea, Uniswap…).
🌟Inclure un lexique personnel des termes clés (blockchain, NFT, DeFi, smart contract, wallet…).
🚀
Comment réaliser ce projet
1
Relis le cours et note les 3 grandes ères du web. Pour chacune, écris 2-3 points clés dans tes propres mots.
2
Choisis ton format avant de commencer : HTML, Word ou PDF. Crée le fichier et pose tous les titres de sections en premier.
3
Remplis section par section. Commence par Web 1 → Web 2 → Web 3, puis les concepts spécifiques (blockchain, NFT…).
4
Ajoute ta section "Mon avis". C'est la partie la plus personnelle — qu'est-ce que tu penses de tout ça ? Sceptique sur les NFT ? Enthousiaste pour la décentralisation ?
5
Teste la lisibilité. Peut-on comprendre la différence entre Web 2 et Web 3 en 30 secondes en lisant ta note ?
