Le Spritesheet — Une image, mille poses

Un spritesheet est une seule image PNG qui contient toutes les poses de ton personnage organisées en grille. Au lieu de charger 20 fichiers séparés, tu en charges un seul et tu découpes la portion qui t'intéresse à chaque frame.

Chaque ligne = un état. Chaque colonne = une frame d'animation. Largeur totale = 4 × frameWidth, Hauteur = 3 × frameHeight.

Pour charger et découper un spritesheet, on utilise la version à 9 paramètres de drawImage :

ParamètreRôle
imgL'image chargée (new Image())
sx, syPosition source dans le spritesheet (colonne×fw, ligne×fh)
sw, shTaille de la portion à découper (frameWidth, frameHeight)
dx, dyPosition de destination sur le canvas
dw, dhTaille d'affichage sur le canvas
// 1. Charger le spritesheet const sprite = new Image(); sprite.src = 'personnage.png'; // 2. Dimensions d'une frame const FW = 64; // frameWidth : largeur d'une frame en px const FH = 64; // frameHeight : hauteur d'une frame en px // 3. Dessiner une frame précise // row=0 (idle), col=2 (3ème frame) const row = 0; // ligne dans le spritesheet const col = 2; // colonne dans le spritesheet ctx.drawImage( sprite, col * FW, row * FH, // sx, sy : position source FW, FH, // sw, sh : taille source joueur.x, joueur.y, // dx, dy : position canvas FW, FH // dw, dh : taille affichée );
💡Où trouver des spritesheets gratuits ? itch.io (Free assets), opengameart.org et kenney.nl proposent des milliers d'assets en CC0 (domaine public).

Animation Frame par Frame

L'animation, c'est changer de frame au bon moment. On ne change pas à chaque frame de la game loop (60fps serait trop rapide) — on utilise un compteur pour ralentir la cadence.

// Variables d'animation let currentFrame = 0; // frame actuelle dans la ligne let animTimer = 0; // compteur de frames game loop const FRAME_DELAY = 8; // changer de frame toutes les 8 frames (~7fps) const NB_FRAMES = 4; // nombre de frames dans l'animation function updateAnimation() { animTimer++; if (animTimer >= FRAME_DELAY) { animTimer = 0; currentFrame = (currentFrame + 1) % NB_FRAMES; // boucle sur les frames } } function drawPersonnage(row) { ctx.drawImage( sprite, currentFrame * FW, row * FH, FW, FH, joueur.x, joueur.y, FW, FH ); } // Dans la game loop : function update() { updateAnimation(); // ... reste de la physique }
🎬 Simulation d'animation — 4 frames, FRAME_DELAY réglable
⚡Un FRAME_DELAY de 6-8 donne une animation fluide à ~60fps. Plus la valeur est petite, plus l'animation est rapide. Une course utilisera 4-5, une marche 8-10.

États du personnage — Idle, Marche, Course, Saut

Chaque état correspond à une ligne différente dans le spritesheet. On maintient une variable d'état qui change selon les inputs et la physique, et on dessine la ligne correspondante.

// Les états possibles (correspond aux lignes du spritesheet) const ETATS = { IDLE : 0, // ligne 0 du spritesheet MARCHE : 1, // ligne 1 COURSE : 2, // ligne 2 SAUT : 3, // ligne 3 }; let etatActuel = ETATS.IDLE; function mettreAJourEtat() { if (!joueur.auSol) { etatActuel = ETATS.SAUT; // priorité : en l'air = SAUT } else if (touches['Shift'] && (touches['ArrowLeft'] || touches['ArrowRight'])) { etatActuel = ETATS.COURSE; // Shift + flèche = COURSE } else if (touches['ArrowLeft'] || touches['ArrowRight']) { etatActuel = ETATS.MARCHE; // flèche seule = MARCHE } else { etatActuel = ETATS.IDLE; // rien = IDLE } // Miroir horizontal si le personnage va à gauche if (touches['ArrowLeft']) { ctx.save(); ctx.scale(-1, 1); ctx.drawImage(sprite, /* ... */ -joueur.x - FW, joueur.y, FW, FH); ctx.restore(); } else { drawPersonnage(etatActuel); } }

Décor & Parallaxe — La profondeur visuelle

La parallaxe crée une illusion de profondeur : les éléments loin (ciel, montagnes) défilent lentement, les éléments proches (arbres, sol) défilent vite. C'est la même technique que dans les jeux 2D classiques.

// Plusieurs couches de fond (de la plus loin à la plus proche) const couches = [ { img: imgCiel, vitesse: 0.1, x: 0 }, // ciel : très lent { img: imgMontagnes, vitesse: 0.3, x: 0 }, // montagnes : lent { img: imgArbres, vitesse: 0.6, x: 0 }, // arbres : moyen { img: imgSol, vitesse: 1.0, x: 0 }, // sol : vitesse du joueur ]; function updateCouches(vitesseJoueur) { couches.forEach(function(c) { c.x -= vitesseJoueur * c.vitesse; // décale selon la profondeur if (c.x <= -canvas.width) c.x = 0; // boucle infinie }); } function drawCouches() { couches.forEach(function(c) { // Dessiner deux fois pour le scroll infini ctx.drawImage(c.img, c.x, 0, canvas.width, canvas.height); ctx.drawImage(c.img, c.x + canvas.width, 0, canvas.width, canvas.height); }); }

Son & Musique — HTMLAudioElement

Pour ajouter du son à ton jeu, la méthode la plus simple est HTMLAudioElement. Pour la musique de fond (loopée) et des effets sonores (SFX) au moment d'un événement.

// Musique de fond (boucle infinie) const musique = new Audio('sons/musique.mp3'); musique.loop = true; musique.volume = 0.4; // entre 0 et 1 musique.play(); // Effets sonores (SFX) const sonSaut = new Audio('sons/saut.wav'); const sonPiece = new Audio('sons/piece.wav'); const sonDegat = new Audio('sons/degat.wav'); // Jouer un SFX (cloner pour pouvoir le rejouer rapidement) function jouerSon(son) { const clone = son.cloneNode(); clone.play(); } // Dans la game loop, quand le joueur saute : if (touches[' '] && joueur.auSol) { joueur.vy = FORCE_SAUT; jouerSon(sonSaut); // ← déclencher le son ici }
Formats compatibles
MP3 — musique (compression bonne)
OGG — open source
WAV — SFX courts (qualité max)
WebM — alternatif moderne
Autoplay bloqué
Les navigateurs bloquent l'autoplay sans interaction utilisateur. Commence la musique sur un clic ou une touche, pas au chargement.
🎵Où trouver des sons gratuits ? freesound.org, opengameart.org, pixabay.com/music. Pour les SFX 8-bit, essaie jsfxr.com (génère des sons directement dans le navigateur).
