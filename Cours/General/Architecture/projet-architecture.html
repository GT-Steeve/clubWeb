🗂️ Projet — Architecture de projet

Crée ton propre site multi-pages dans VS Code !

Projet guidé Architecture Chemins de fichiers VS Code
🎯
Objectif du projet

Tu as compris comment organiser les fichiers d'un projet web et écrire des chemins relatifs. Maintenant, c'est à toi de le faire pour de vrai — dans VS Code, avec tes propres mains.

Le but : créer un petit site multi-pages en respectant l'architecture du cours. Le thème est entièrement libre — choisis un sujet qui te plaît ! Tu peux utiliser l'IA et le cours pour t'aider, mais c'est toi qui dois créer les fichiers, les dossiers et écrire les chemins.

💡 L'important ici n'est pas le design de ton site — c'est l'organisation de tes fichiers et la correction de tes chemins. Un site tout simple avec la bonne architecture vaut mieux qu'un beau site avec des erreurs de chemins !
📁
Structure de fichiers requise

Ton projet doit respecter cette architecture. Le nom du dossier racine et les contenus sont libres, mais les noms index.html, Assets/, css/, js/ et img/ sont obligatoires.

mon-projet/ ← ton dossier racine (nom libre)
│
├── index.html ← page d'accueil (obligatoire)
│
├── 📁 pages/ ← sous-dossier pour les autres pages
│ └── contact.html ← 2e page HTML (nom et contenu libres)
│
└── 📁 Assets/ ← tous les fichiers de support
├── 📁 css/
│ └── style.css ← styles communs aux deux pages
├── 📁 js/
│ └── script.js ← javascript (peut être vide)
└── 📁 img/
└── image.png ← au moins une image
⚠️ Respecte les majuscules : le dossier s'appelle Assets (A majuscule). Les noms de fichiers et dossiers ne doivent jamais contenir d'espaces — utilise des tirets à la place.
📋
Cahier des charges — Exigences obligatoires

Ces points techniques sont non-négociables. Le contenu et le design restent entièrement libres :

✅ Le dossier racine contient index.html et le dossier Assets/ (avec A majuscule).
✅ Un dossier pages/ existe avec au moins une deuxième page HTML.
✅ Dans index.html, le CSS est lié avec le chemin relatif : Assets/css/style.css
✅ Depuis la page dans pages/, le CSS est lié avec : ../Assets/css/style.css
✅ index.html contient un lien vers la page dans pages/ :
<a href="pages/contact.html">…</a>
✅ La page dans pages/ a un lien de retour vers l'accueil :
<a href="../index.html">…</a>
✅ Au moins une image dans Assets/img/ est affichée dans le site avec le chemin relatif correct.
✅ Aucun chemin absolu dans le code — pas de C:/Users/… ni file:///. Uniquement des chemins relatifs.
⭐
Points bonus — Pour aller plus loin

Ces éléments ne sont pas obligatoires, mais ils montrent que tu maîtrises bien le sujet :

🌟 Créer une troisième page HTML dans pages/ et la lier depuis index.html.
🌟 Lier Assets/js/script.js correctement depuis les deux pages (chemin différent selon la position).
🌟 Utiliser plusieurs images avec des chemins corrects depuis la racine ET depuis un sous-dossier.
🌟 Ajouter un README.md à la racine qui décrit brièvement ton projet.
🧭
Rappel — Les chemins à écrire

Voici exactement les chemins que tu vas devoir utiliser selon d'où tu te trouves :

Depuis index.html (à la racine du projet)
Assets/css/style.css
Assets/img/image.png
pages/contact.html
Depuis pages/contact.html (dans un sous-dossier)
../Assets/css/style.css
../Assets/img/image.png
../index.html
💡 Le .. signifie "remonter d'un dossier". Depuis pages/, un .. remonte à la racine du projet. N'oublie jamais le / après le .. !
🚀
Comment réaliser ce projet
1
Choisis un thème — Ton portfolio, un site sur ton jeu préféré, un restaurant fictif, un club sportif... Peu importe. Choisis quelque chose qui te motive à coder !
2
Crée la structure dans VS Code — Ouvre VS Code, crée un nouveau dossier de projet, puis crée manuellement les fichiers et dossiers requis en suivant l'arbre ci-dessus. Clic droit dans l'explorateur → "Nouveau dossier" / "Nouveau fichier".
3
Commence par les chemins — Dans chaque fichier HTML, commence par lier le CSS avec le bon chemin relatif AVANT d'écrire le contenu. Ouvre dans le navigateur et vérifie avec F12 → Console : aucune erreur en rouge.
4
Construis le contenu — Maintenant que les chemins fonctionnent, ajoute ton contenu HTML et tes styles CSS. Personnalise comme tu le souhaites !
5
Teste la navigation — Clique sur tous les liens entre les pages et vérifie que tu peux naviguer sans erreur dans les deux sens.
6
Utilise le cours et l'IA pour débloquer — Si tu es bloqué, décris précisément ton problème : "Mon CSS ne se charge pas depuis pages/contact.html, voici ma structure de fichiers...". L'IA t'aide à comprendre, pas à faire à ta place.
