Méthodologie Analyse Canvas Flappy Bird
🎮
La méthode : couche par couche
Ne jamais tout coder d'un coup

Reproduire un jeu qu'on aime, c'est l'un des meilleurs exercices pour progresser. Mais le piège est de vouloir tout faire en même temps. Un bon clone se construit en couches progressives :

1
La mécanique centrale — ce qui rend le jeu unique
2
Les obstacles ou adversaires — ce qui menace le joueur
3
La détection de collision — quand ça touche, que se passe-t-il ?
4
Le score et la progression — récompense et difficulté croissante
5
La machine à états — titre, jeu, game over
6
Ta variante — ce qui fait que c'est TON jeu
Règle d'or : à chaque étape, le jeu doit être jouable. Une mécanique qui marche > un jeu entier qui ne compile pas.

Dans ce cours on va cloner Flappy Bird — un classique minimaliste où chaque concept est bien isolé. Mais la méthode s'applique à n'importe quel jeu : Snake, Breakout, Space Invaders…

1
Analyser avant de coder
Décomposer le jeu en problèmes simples

Avant d'ouvrir l'éditeur, passe 5 minutes à observer le jeu comme un développeur. Pose-toi ces questions :

🕹️ Core loop
Qu'est-ce que le joueur fait toutes les secondes ? Cliquer pour faire voler l'oiseau.
🌍 Physique
Quelles forces s'appliquent ? Gravité constante vers le bas, impulsion vers le haut au clic.
🚧 Obstacles
Comment apparaissent-ils ? Tuyaux générés aléatoirement, défilant de droite à gauche.
🏆 Score
Qu'est-ce qui est compté ? Un point par paire de tuyaux passée. Vitesse augmente.
📺 États
Quels écrans ? Titre (attente) → Jeu → Game Over (score + relance).
💥 Collision
Quand est-ce perdu ? Toucher un tuyau, le sol ou le plafond.
💡 Méthode : Dessine le jeu sur papier. Repère les objets (oiseau, tuyau, sol), leurs propriétés (position, vitesse) et ce qui change à chaque frame. Ce schéma deviendra ta feuille de route.
2
Le noyau — Gravité et saut
Coder d'abord ce qui rend le jeu unique

Le cœur de Flappy Bird tient en trois lignes : une position verticale, une vitesse verticale, et une gravité. Commence uniquement par ça — sans tuyaux, sans score.

// Les 3 variables du noyau
let y  = canvas.height / 2; // position verticale de l'oiseau
let vy = 0;                  // vitesse verticale
const GRAVITE    = 0.4;     // accélération vers le bas (px/frame²)
const FORCE_SAUT = -8;      // impulsion vers le haut (négatif = haut)

function update() {
  vy += GRAVITE; // la gravité accélère la chute
  y  += vy;      // la vitesse déplace l'oiseau
}

// Au clic : impulsion vers le haut
canvas.addEventListener('click', () => { vy = FORCE_SAUT; });
document.addEventListener('keydown', (e) => {
  if (e.code === 'Space') { e.preventDefault(); vy = FORCE_SAUT; }
});

Teste ça. L'oiseau doit tomber et remonter au clic. Si c'est bon, tu as le noyau. Tout le reste est de l'ajout.

Démo — Cliquer ou Espace pour faire voler l'oiseau (juste la physique, pas encore de tuyaux)
Physique en deux lignes : vy += GRAVITE simule l'attraction gravitationnelle — la vitesse augmente chaque frame. y += vy applique cette vitesse à la position. Le saut réinitialise simplement vy à une valeur négative (vers le haut).
3
Les obstacles — Tuyaux défilants
Générer et faire scroller des objets

Faire défiler le monde de droite à gauche crée l'illusion de mouvement. Chaque tuyau est un objet avec une position x et une hauteur de gap aléatoire. On en génère un tous les N frames.

let tuyaux = [];          // tableau des tuyaux actifs
let frame  = 0;           // compteur de frames
let vitesse = 3;          // vitesse de défilement (px/frame)

const INTERVALLE = 90;   // frames entre deux tuyaux
const ECART      = 130;  // espace vertical entre tuyau haut et bas
const LARG       = 60;   // largeur d'un tuyau

function update() {
  frame++;

  // ① Générer un nouveau tuyau toutes les INTERVALLE frames
  if (frame % INTERVALLE === 0) {
    const gapY = 55 + Math.random() * (140); // hauteur aléatoire du gap
    tuyaux.push({ x: canvas.width, gapY: gapY, passé: false });
  }

  // ② Faire défiler tous les tuyaux vers la gauche
  tuyaux.forEach(t => t.x -= vitesse);

  // ③ Supprimer les tuyaux sortis de l'écran
  tuyaux = tuyaux.filter(t => t.x > -LARG - 10);
}

function drawTuyaux() {
  tuyaux.forEach(function(t) {
    // Tuyau du haut : de 0 jusqu'au gap
    ctx.fillStyle = '#16A34A';
    ctx.fillRect(t.x, 0, LARG, t.gapY);
    // Tuyau du bas : depuis gap + ECART jusqu'au sol
    ctx.fillRect(t.x, t.gapY + ECART, LARG, canvas.height - (t.gapY + ECART));
    // Chapeau (légèrement plus large)
    ctx.fillStyle = '#22C55E';
    ctx.fillRect(t.x - 6, t.gapY - 22, LARG + 12, 22);
    ctx.fillRect(t.x - 6, t.gapY + ECART, LARG + 12, 22);
  });
}
💡 Scrolling sans camera : Plutôt que de "bouger la caméra", on fait simplement reculer tout le monde. L'oiseau reste à x fixe (ex: 100), et les tuyaux avancent vers lui. Même effet, code beaucoup plus simple.
4
Détection de collision
L'oiseau touche-t-il un tuyau ?

La collision entre un oiseau et un tuyau se détecte avec la technique AABB : deux rectangles se chevauchent si leurs bords se croisent sur les deux axes.

function collision(oiseau, tuyau) {
  // Rectangle approximatif de l'oiseau (légèrement réduit = plus juste)
  const ox = oiseau.x - 11, oy = oiseau.y - 10;
  const ow = 22,          oh = 20;

  // Pas de chevauchement horizontal ? → pas de collision
  if (ox + ow <= tuyau.x || ox >= tuyau.x + LARG) return false;

  // L'oiseau est dans l'écart ? → pas de collision
  if (oy >= tuyau.gapY && oy + oh <= tuyau.gapY + ECART) return false;

  return true; // touche le tuyau du haut ou du bas
}

// Dans update() :
tuyaux.forEach(function(t) {
  if (collision(oiseau, t)) {
    gameState = ETATS.GAMEOVER; // → game over !
  }
});

// Sol et plafond
if (oiseau.y + 10 >= SOL) { gameState = ETATS.GAMEOVER; }
if (oiseau.y - 10 <= 0)  { oiseau.y = 10; oiseau.vy = 0; }
⚠️ Hitbox généreuse : Le rectangle de collision légèrement plus petit que le sprite donne l'impression au joueur que les collisions sont "justes". Une hitbox trop exacte paraît injuste. Réduis la de 20-30% — c'est standard dans tous les jeux.
5
Score et progression
Compter les tuyaux passés, accélérer le jeu

Un point est marqué quand l'oiseau dépasse le bord droit d'un tuyau. La difficulté augmente en accélérant le défilement toutes les 5 réussites. Le meilleur score est sauvegardé dans localStorage.

let score    = 0;
let meilleur = parseInt(localStorage.getItem('flappy_best') || '0');

// Dans update(), après avoir déplacé les tuyaux :
tuyaux.forEach(function(t) {
  // L'oiseau a-t-il dépassé ce tuyau pour la première fois ?
  if (!t.passé && t.x + LARG < oiseau.x) {
    t.passé = true;
    score++;

    // Accélérer tous les 5 tuyaux
    if (score % 5 === 0) vitesse += 0.3;
  }
});

// Sauvegarder le meilleur score au game over
function onGameOver() {
  if (score > meilleur) {
    meilleur = score;
    localStorage.setItem('flappy_best', meilleur);
  }
  gameState = ETATS.GAMEOVER;
}
💡 Difficulté progressive : Augmenter la vitesse palier par palier (et non de façon linéaire) donne des "niveaux" naturels sans avoir à en coder. À partir de 10-15 tuyaux, on peut aussi réduire ECART pour diminuer l'espace libre.
6
Machine à états complète
Titre, jeu, game over — le même pattern que dans Game Design

On applique exactement le même pattern que dans le cours Game Design : gameState détermine ce que la boucle affiche. Pour Flappy Bird, 3 états suffisent.

TITRE
→ clic
JEU
→ collision
GAMEOVER
→ clic
TITRE
const ETATS = { TITRE: 'titre', JEU: 'jeu', OVER: 'over' };
let gameState = ETATS.TITRE;

function loop() {
  ctx.clearRect(0, 0, W, H);
  switch (gameState) {
    case ETATS.TITRE: drawTitre();            break;
    case ETATS.JEU:   update(); drawJeu();  break;
    case ETATS.OVER:  drawGameOver();        break;
  }
  requestAnimationFrame(loop);
}

// Un seul listener gère tout selon l'état
canvas.addEventListener('click', function() {
  if (gameState === ETATS.TITRE) { reinit(); gameState = ETATS.JEU; }
  else if (gameState === ETATS.JEU)  { oiseau.vy = FORCE_SAUT; }
  else if (gameState === ETATS.OVER)  { gameState = ETATS.TITRE; }
});

function reinit() {
  oiseau.y = H / 2; oiseau.vy = 0;
  tuyaux = []; score = 0; frame = 0; vitesse = 3;
}
7
Ajouter ta variante
C'est là que le clone devient TON jeu

Un clone fidèle est un excellent exercice. Mais le vrai plaisir, c'est d'y ajouter ta touche. Une variante peut être thématique, mécanique ou les deux :

🎨 Variantes thématiques
  • Vaisseau dans l'espace → météorites
  • Dauphin sous-marin → récifs
  • Voiture entre des camions
  • Grenouille entre des lianes
⚙️ Variantes mécaniques
  • Double saut
  • Gravité inversée (toggle)
  • Bouclier temporaire
  • Obstacles qui accélèrent brusquement
// Exemple : double saut
let sauts = 0; // compteur de sauts depuis le dernier atterrissage

canvas.addEventListener('click', function() {
  if (gameState === ETATS.JEU && sauts < 2) {
    oiseau.vy = FORCE_SAUT;
    sauts++;
  }
});
// Réinitialiser quand on passe entre deux tuyaux (simuler "sol")
// ou ajouter une vraie platforme que l'oiseau peut toucher

// Exemple : gravité inversée au bouton G
let gravité = 0.4;
document.addEventListener('keydown', (e) => {
  if (e.code === 'KeyG') gravité = -gravité; // inverser !
});
Le principe : Une variante mécanique ne demande souvent que quelques lignes. Tu as déjà toute l'infrastructure — physics, scrolling, collisions, états. Ajouter une feature, c'est souvent juste changer une variable ou ajouter une condition.
