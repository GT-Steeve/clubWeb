🏗️ Projet — Mon site enrichi en HTML avancé

Reprends ton site CSS et ajoute les nouvelles balises sémantiques — navigation, vidéo, articles, sections et plus.

HTML sémantique CSS existant <nav> <article> <video> <details> Structure avancée
🎯
Objectif du projet

Ce projet est la suite directe du projet CSS. Tu repars du même site que tu as déjà stylisé — et tu l'enrichis avec les nouvelles balises sémantiques du cours HTML avancé.

L'objectif : rendre la page plus riche, plus professionnelle et plus accessible grâce à un balisage sémantique correct. Une page bien balisée est mieux comprise par les moteurs de recherche, les lecteurs d'écran et les autres développeurs qui liront ton code.

🧠 Sémantique = donner du sens à chaque partie du code. <nav> dit "c'est un menu", <article> dit "c'est un contenu autonome", <aside> dit "c'est une info secondaire". Les <div> ne disent rien — utilise-les en dernier recours.
🏷️
Les balises à utiliser dans ce projet

Tu dois intégrer au moins 5 de ces balises dans ton site, là où elles ont du sens :

Balise Rôle Exemple d'usage
<nav> Menu de navigation principal Liens vers les sections de la page
<article> Contenu autonome et réutilisable Une fiche, un post, une recette
<section> Groupe thématique avec un titre Une rubrique de la page
<aside> Information complémentaire Citation, fun fact, encart de stats
<video> Vidéo intégrée avec contrôles Trailer, tutoriel, présentation
<figure> / <figcaption> Image avec légende Photo illustrée + description
<details> / <summary> Accordéon natif HTML FAQ, anecdote cachée, spoiler
<time> Date ou heure sémantique Date de publication, année
⚠️ Ne remplace pas toutes tes <div> d'un coup au hasard. Pose-toi la question : "Ce contenu est-il un menu ? Un article ? Une section ?" Si oui, utilise la balise correspondante. Sinon, garde la <div>.
📋
Cahier des charges — Exigences obligatoires
✅ Ajouter un <nav> avec au moins 3 liens internes vers des sections de la page (ancres #id).
✅ Remplacer les <div> de contenu principal par des <section> avec un id correspondant aux liens du nav.
✅ Utiliser <article> pour au moins un élément de contenu autonome (une fiche, une recette, un post…).
✅ Utiliser <aside> pour une information complémentaire à côté du contenu principal (fun fact, encart…).
✅ Ajouter une <figure> avec une <figcaption> pour au moins une image.
✅ Ajouter au moins un bloc <details> + <summary> (accordéon/FAQ ou anecdote cachée).
✅ Le CSS existant du projet précédent est conservé et ajusté pour les nouvelles balises (le site reste visuellement cohérent).
⭐
Points bonus
🌟 Intégrer une <video> avec controls et un texte de remplacement entre les balises.
🌟 Utiliser <time datetime="..."> pour dater une information (ex : année de sortie, date de publication).
🌟 Styliser le <nav> en CSS pour en faire une barre de navigation visuellement distincte (fond, liens côte à côte).
🌟 Rendre le <nav> "sticky" (position: sticky; top: 0;) pour qu'il reste visible en scrollant.
🌟 Ajouter plusieurs <details> pour créer une FAQ complète sur ton sujet.
🚀
Comment réaliser ce projet
1
Ouvre ton projet CSS existant. Relis le code HTML pour identifier les <div> qui pourraient être remplacées par des balises sémantiques.
2
Ajoute le <nav> juste après le <header>. Donne un id à chaque section principale et crée les liens correspondants.
3
Remplace les <div> de section par des <section> et identifie les contenus qui méritent d'être des <article>.
4
Ajoute l'<aside> dans une section qui a une info complémentaire naturelle. Stylise-le différemment (fond légèrement teinté, bordure…).
5
Remplace un <img> par une <figure><img><figcaption>…</figcaption></figure> et ajoute un bloc <details>.
6
Ajuste le CSS pour les nouvelles balises. Vérifie que le site reste cohérent visuellement. Teste dans le navigateur.
