Le flux d'une requête Django

Quand un utilisateur visite une URL, Django suit un cycle précis. Remets ces étapes dans l'ordre.

Ordre correct — flux d'une requête Django
Étape 1L'utilisateur envoie une requête HTTP
Étape 2Django cherche l'URL dans urls.py
Étape 3La View correspondante est appelée
Étape 4La View interroge la BDD via l'ORM
Étape 5La View passe les données au Template
Étape 6Le Template génère le HTML final
Étape 7Django renvoie la réponse HTTP
