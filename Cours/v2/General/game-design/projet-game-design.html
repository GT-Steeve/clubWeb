Ce projet fait suite au projet Platformer Canvas. Tu as déjà un jeu qui tourne — personnage, plateformes, pièces, game loop. On va maintenant lui donner une vraie architecture : un écran titre, un menu, plusieurs niveaux avec des données, un timer et un tableau de scores sauvegardé dans le navigateur.

Progression 0 / 6 étapes
1
Machine à états — Transformer la boucle
▼

Actuellement ta boucle loop() dessine directement le jeu. On va la transformer en aiguilleur : selon la valeur de gameState, elle appelle la bonne fonction d'écran.

Ajouter en haut de script.js — avant loop()
// Toutes les valeurs possibles de gameState const ETATS = { TITRE: 'titre', MENU: 'menu', NIVEAUX: 'niveaux', JEU: 'jeu', VICTOIRE: 'victoire', GAMEOVER: 'gameover', SCORES: 'scores' }; let gameState = ETATS.TITRE; // on commence par l'écran titre
Remplacer le contenu de loop()
function loop() { ctx.clearRect(0, 0, canvas.width, canvas.height); switch (gameState) { case ETATS.TITRE: drawTitre(); break; case ETATS.MENU: drawMenu(); break; case ETATS.NIVEAUX: drawNiveaux(); break; case ETATS.JEU: updateJeu(); drawJeu(); break; case ETATS.VICTOIRE: drawVictoire(); break; case ETATS.GAMEOVER: drawGameOver(); break; case ETATS.SCORES: drawScores(); break; } requestAnimationFrame(loop); } loop();
💡
Changer d'écran = changer la variable : gameState = ETATS.MENU. La prochaine frame affiche automatiquement le bon écran. Tu dois aussi créer des fonctions vides (function drawTitre(){}) pour chaque état pour éviter les erreurs.
2
Écran titre — Dessin + bouton cliquable
▼

L'écran titre accueille le joueur avec un fond, un titre et un bouton dessiné sur le canvas. La détection de clic utilise getBoundingClientRect() pour corriger les coordonnées si le CSS redimensionne le canvas.

drawTitre() — dessiner le titre et le bouton
let btnTitre = null; // mémorise le rect du bouton pour le clic function drawTitre() { // Fond dégradé const g = ctx.createLinearGradient(0, 0, 0, canvas.height); g.addColorStop(0, '#0F172A'); g.addColorStop(1, '#1E3A5F'); ctx.fillStyle = g; ctx.fillRect(0, 0, canvas.width, canvas.height); // Titre ctx.fillStyle = '#FBBF24'; ctx.font = '800 42px Nunito'; ctx.textAlign = 'center'; ctx.fillText('🎯 MON JEU', canvas.width / 2, 90); // Bouton "Jouer" const bx = canvas.width / 2 - 100, by = 140; const bw = 200, bh = 46; roundRect(ctx, bx, by, bw, bh, 12); ctx.fillStyle = '#F43F5E'; ctx.fill(); ctx.fillStyle = '#fff'; ctx.font = '700 18px Nunito'; ctx.fillText('▶ Jouer', canvas.width / 2, by + bh / 2 + 6); btnTitre = { x: bx, y: by, w: bw, h: bh }; }
Gestionnaire de clic — à ajouter une seule fois
canvas.addEventListener('click', function(e) { const r = canvas.getBoundingClientRect(); const sx = canvas.width / r.width; // ratio CSS → pixels internes const sy = canvas.height / r.height; const mx = (e.clientX - r.left) * sx; const my = (e.clientY - r.top) * sy; if (gameState === ETATS.TITRE && btnTitre) { if (mx >= btnTitre.x && mx <= btnTitre.x + btnTitre.w && my >= btnTitre.y && my <= btnTitre.y + btnTitre.h) { gameState = ETATS.MENU; // → aller au menu } } // Tu ajouteras les clics des autres états ici });
📐
Si ton CSS redimensionne le canvas avec max-width, la taille affichée diffère de la résolution interne. Le ratio canvas.width / r.width corrige ça. Sans lui, le clic passe à côté des boutons.
3
Menu & Sélecteur de niveaux
▼

Le menu propose les options (Jouer, Scores). Le sélecteur affiche les niveaux disponibles sous forme de cartes — les niveaux verrouillés apparaissent grisés avec un cadenas.

Données du menu et des niveaux
const MENU_BTNS = [ { label: '▶ Jouer', action: () => { gameState = ETATS.NIVEAUX; } }, { label: '🏆 Scores', action: () => { gameState = ETATS.SCORES; } } ]; const NIVEAUX_LIST = [ { id: 1, nom: 'La forêt', couleur: '#16A34A', requis: 0 }, { id: 2, nom: 'Les grottes', couleur: '#0284C7', requis: 1 }, { id: 3, nom: 'Le volcan', couleur: '#DC2626', requis: 2 } ]; let niveauxDebloqués = chargerProgression(); // depuis localStorage
drawMenu() — boutons cliquables sur le canvas
function drawMenu() { /* dessine fond + titre "MENU PRINCIPAL" */ MENU_BTNS.forEach(function(btn, i) { const bx = canvas.width / 2 - 120; const by = 80 + i * 60; const bw = 240, bh = 44; /* dessine le rectangle + texte du bouton */ btn.rect = { x: bx, y: by, w: bw, h: bh }; // mémoriser pour le clic }); } function drawNiveaux() { NIVEAUX_LIST.forEach(function(niv, i) { const col = i % 2, row = Math.floor(i / 2); const cx = 60 + col * 240, cy = 60 + row * 120; const ok = niveauxDebloqués >= niv.requis + 1; roundRect(ctx, cx, cy, 200, 100, 14); ctx.fillStyle = ok ? niv.couleur : '#444'; ctx.fill(); ctx.fillStyle = '#fff'; ctx.font = '800 16px Nunito'; ctx.textAlign = 'center'; ctx.fillText(ok ? niv.nom : '🔒', cx + 100, cy + 55); niv.rect = { x: cx, y: cy, w: 200, h: 100 }; // mémoriser pour le clic }); }
Dans le gestionnaire 'click' — ajouter les vérifications
// Dans le menu : clic sur un bouton if (gameState === ETATS.MENU) { MENU_BTNS.forEach(function(btn) { if (btn.rect && mx >= btn.rect.x && mx <= btn.rect.x + btn.rect.w && my >= btn.rect.y && my <= btn.rect.y + btn.rect.h) { btn.action(); // appelle la fonction liée à ce bouton } }); } // Dans le sélecteur : clic sur une carte de niveau if (gameState === ETATS.NIVEAUX) { NIVEAUX_LIST.forEach(function(niv) { if (niv.rect && mx >= niv.rect.x && mx <= niv.rect.x + niv.rect.w && my >= niv.rect.y && my <= niv.rect.y + niv.rect.h) { if (niveauxDebloqués >= niv.requis + 1) { // débloqué ? chargerNiveau(niv.id); gameState = ETATS.JEU; } } }); }
🎮
Chaque bouton et carte mémorise son rectangle dans .rect à chaque frame de dessin. Le gestionnaire de clic n'a qu'à vérifier si le point de clic est dans ce rectangle.
4
localStorage — Scores et progression
▼

localStorage garde les données même après fermeture du navigateur. On y stocke les 10 meilleurs scores et le nombre de niveaux débloqués, convertis en string avec JSON.stringify().

Fonctions de sauvegarde et chargement
// ─── Scores ─────────────────────────────────────────── function chargerScores() { const raw = localStorage.getItem('monJeu_scores'); return raw ? JSON.parse(raw) : []; } function sauvegarderScore(nom, points, niveauId) { const scores = chargerScores(); scores.push({ nom, points, niveau: niveauId }); scores.sort((a, b) => b.points - a.points); localStorage.setItem('monJeu_scores', JSON.stringify(scores.slice(0, 10))); } // ─── Progression (niveaux débloqués) ────────────────── function chargerProgression() { return parseInt(localStorage.getItem('monJeu_niveaux') || '1'); } function sauvegarderProgression() { localStorage.setItem('monJeu_niveaux', niveauxDebloqués.toString()); } // ─── Afficher les scores sur le canvas ──────────────── function drawScores() { /* dessine fond + titre "MEILLEURS SCORES" */ const scores = chargerScores(); if (scores.length === 0) { ctx.fillStyle = '#888'; ctx.font = '600 16px Nunito'; ctx.textAlign = 'center'; ctx.fillText('Aucun score enregistré', canvas.width / 2, canvas.height / 2); } scores.forEach(function(s, i) { ctx.fillStyle = '#fff'; ctx.font = '700 14px Nunito'; ctx.textAlign = 'left'; ctx.fillText((i+1) + '. ' + s.nom + ' — ' + s.points + ' pts', 60, 80 + i * 28); }); /* bouton "← Retour" pour revenir au menu */ }
💾
localStorage ne stocke que des strings. Un tableau ou un objet doit passer par JSON.stringify() avant d'être sauvegardé, et JSON.parse() après avoir été chargé.
5
Structure de niveaux — Données et chargement
▼

Chaque niveau est un objet de données : plateformes, ennemis, position de départ, temps et nombre de pièces. On le charge avec une copie profonde pour ne pas altérer les données originales si on relance le niveau.

NIVEAU_DATA — définir les niveaux
const NIVEAU_DATA = [ { id: 1, tempsMax: 60, nbPieces: 5, posDepart: { x: 40, y: 280 }, plateformes: [ { x:0, y:340, w:600, h:20 }, // sol { x:90, y:270, w:130, h:15 }, { x:290, y:210, w:130, h:15 }, { x:430, y:270, w:130, h:15 } ], ennemis: [ { x:250, y:320, vx:1, patrol: [200, 350] } ] }, { id: 2, tempsMax: 45, nbPieces: 8, posDepart: { x: 40, y: 280 }, plateformes: [ /* tes plateformes niveau 2 */ ], ennemis: [ /* tes ennemis niveau 2 */ ] } ]; let niveauActuel = null;
chargerNiveau() — copie profonde + initialisation
function chargerNiveau(n) { // Copie profonde — indispensable pour ne pas modifier NIVEAU_DATA niveauActuel = JSON.parse(JSON.stringify(NIVEAU_DATA[n - 1])); joueur.x = niveauActuel.posDepart.x; joueur.y = niveauActuel.posDepart.y; joueur.vx = joueur.vy = 0; piecesRecuperees = 0; genererPieces(niveauActuel.nbPieces); // réinitialise le tableau pieces[] timer = niveauActuel.tempsMax * 60; // convertir secondes → frames } function niveauTerminé() { const score = Math.round(niveauActuel.nbPieces * 1000 + (timer / 60) * 100); sauvegarderScore('Joueur', score, niveauActuel.id); // Débloquer le niveau suivant niveauxDebloqués = Math.max(niveauxDebloqués, niveauActuel.id + 1); sauvegarderProgression(); gameState = ETATS.VICTOIRE; }
⚠️
Sans JSON.parse(JSON.stringify()), modifier les positions des ennemis pendant le jeu modifierait aussi NIVEAU_DATA. Au second lancement du niveau, les ennemis seraient déplacés et le niveau corrompu.
6
Timer, HUD, Game Over & Victoire
▼

Le timer se décrémente d'un à chaque frame. Le HUD l'affiche en secondes. Quand il tombe à zéro : Game Over. Quand toutes les pièces sont ramassées : Victoire et sauvegarde du score.

Ajouter en haut de script.js
let timer = 0; // en frames — 60 frames ≈ 1 seconde à 60fps
updateJeu() — remplace ton update() actuel
function updateJeu() { update(); // ton update() existant (mouvement, gravité, collisions, pièces) timer--; if (timer <= 0) { gameState = ETATS.GAMEOVER; return; } if (piecesRecuperees >= niveauActuel.nbPieces) { niveauTerminé(); return; } } function drawJeu() { draw(); // ton draw() existant (fond, plateformes, pièces, joueur) drawHUD(); // par-dessus : timer + pièces collectées }
drawHUD() — afficher le timer et les pièces
function drawHUD() { const sec = Math.ceil(timer / 60); // arrondir vers le haut // Timer (rouge si ≤ 10 secondes) ctx.fillStyle = sec <= 10 ? '#F43F5E' : '#fff'; ctx.font = '800 16px Nunito'; ctx.textAlign = 'right'; ctx.fillText('⏱ ' + sec + 's', canvas.width - 16, 28); // Pièces collectées ctx.fillStyle = '#FBBF24'; ctx.textAlign = 'left'; ctx.fillText('🪙 ' + piecesRecuperees + '/' + niveauActuel.nbPieces, 16, 28); } function drawVictoire() { /* fond vert + "🎉 VICTOIRE !" + score + bouton "Niveau suivant" */ const score = Math.round(niveauActuel.nbPieces * 1000 + (timer / 60) * 100); /* afficher score */ } function drawGameOver() { /* fond rouge sombre + "💀 GAME OVER" + bouton "Réessayer" */ }
🏆
Math.ceil(timer / 60) affiche le timer en secondes et arrondit vers le haut — le joueur voit "1s" tant qu'il reste au moins 1 frame, jamais "0s" prématurément. Score = pièces × 1000 + (timer / 60) × 100.
💡 Pour aller plus loin

Ton jeu a une machine à états, des niveaux et des scores persistants ? Voici des idées pour aller encore plus loin.

⏸️
Écran Pause
Ajouter un booléen isPaused et l'écoute de la touche Échap. Quand en pause, drawJeu() dessine d'abord le jeu normalement, puis superpose un overlay semi-transparent avec "PAUSE". gameState reste sur 'jeu' — c'est isPaused qui bloque updateJeu().
⭐
Étoiles de performance
Sur l'écran de victoire, afficher 1, 2 ou 3 étoiles selon le temps restant. 3 étoiles si plus de 50 % du temps reste, 2 entre 20 % et 50 %, 1 sinon. Sauvegarder le meilleur résultat par niveau dans localStorage.
✏️
Saisir le nom du joueur
Avant de commencer, utiliser prompt() ou créer un champ HTML positionné par-dessus le canvas pour récupérer nomJoueur. Ce nom sera associé à chaque score sauvegardé dans localStorage.
👾
Ennemis dans NIVEAU_DATA
Ajouter un tableau ennemis dans chaque niveau avec la position et la zone de patrouille de chaque ennemi. Grâce à la copie profonde, leurs positions sont réinitialisées à chaque relance du niveau.
