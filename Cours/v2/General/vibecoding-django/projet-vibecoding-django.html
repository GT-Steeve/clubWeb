🤖 Vibe Coding Django

Suite de django-structure — utilise l'IA pour créer ton premier template HTML et sa view.

Suite de django-structure IA générative 6 étapes ~20 min template + view
🎯
Objectif du projet

Tu repars du projet Django avec l'app blog et sa structure complète (dossiers templates/, static/, urls.py). Tu vas utiliser le vibe coding — écrire des prompts précis à une IA — pour générer un template HTML et une view fonctionnelle, puis les intégrer correctement dans le projet.

💡Règle d'or du vibe coding — Ne colle jamais du code que tu ne peux pas lire et expliquer. Lis le code généré, assure-toi que les noms de fichiers, de views et d'URLs correspondent à ton projet avant de l'intégrer.
Progression 0 / 6 étapes
1
Préparer le contexte à donner à l'IA
Un bon prompt commence par un bon contexte — rien n'est inventé.
✓

Avant de demander quoi que ce soit à l'IA, fournis-lui l'état exact de ton projet. Ouvre ChatGPT, Claude ou Copilot et commence par ce message de contexte :

💬 Prompt de contexte — colle ce texte tel quel
Je travaille sur un projet Django 5. Mon app s'appelle blog. J'ai déjà la structure suivante :

— blog/models.py (vide pour l'instant)
— blog/views.py (vide)
— blog/urls.py avec app_name = 'blog' et urlpatterns vide
— blog/templates/blog/ (dossier vide)
— blog/static/blog/css/style.css (vide)
— monprojet/urls.py avec include('blog.urls') déjà relié

Garde ce contexte en tête pour toutes mes prochaines demandes.
🎯Pourquoi ce contexte ? Sans lui, l'IA invente les noms de fichiers, de views et de variables. Avec ce contexte, elle génère du code qui s'intègre directement dans ton projet.
2
Générer le template HTML avec l'IA
Demander à l'IA de créer blog/templates/blog/index.html.
✓

Dans la même conversation, envoie ce prompt à l'IA :

💬 Prompt — template HTML
Génère le fichier blog/templates/blog/index.html pour une page d'accueil simple du blog. Elle doit :
— Avoir un titre h1 "Mon Blog"
— Afficher un message de bienvenue en paragraphe
— Charger le fichier CSS blog/css/style.css avec {% load static %}
— Utiliser les balises de bloc Django {% block %} pour être extensible
Rien d'autre pour l'instant.

Lis attentivement le code généré avant de l'utiliser. Vérifie que :

✓
{% load static %} est présent en haut du fichier.
✓
Le chemin du CSS correspond bien à 'blog/css/style.css'.
✓
Il n'y a pas d'imports ou de balises inconnues.

Crée le fichier blog/templates/blog/index.html et colle le code généré dedans.

⚠️Si l'IA génère des balises Django que tu ne reconnais pas (comme {% extends %} avec un fichier qui n'existe pas encore), demande-lui de simplifier : "Génère une version sans extends, juste une page HTML standalone."
3
Générer la view avec l'IA
La fonction qui rend le template — dans blog/views.py.
✓

Dans la même conversation, envoie ce prompt :

💬 Prompt — view Django
Génère la view Django pour blog/views.py qui rend le template blog/index.html. La fonction s'appellera index. Elle reçoit request et retourne un render() avec un contexte vide pour l'instant.

La view générée doit ressembler à ceci — vérifie que c'est bien le cas :

blog/views.py — résultat attendu 
from django.shortcuts import render

def index(request):
    return render(request, 'blog/index.html', {})

Colle ce code dans blog/views.py.

🚨Si l'IA génère une class-based view (class IndexView(TemplateView)), demande-lui de la convertir en function-based view : "Convertis en fonction simple, pas de classe." On reste sur le format du cours.
4
Relier la view dans blog/urls.py
Sans cette étape, la page est inaccessible.
✓

Ouvre blog/urls.py et ajoute la route vers la view index :

blog/urls.py — à modifier 
from django.urls import path
from . import views

app_name = 'blog'

urlpatterns = [
    path('', views.index, name='index'),  # ← ajoute cette ligne
]
📌Le chemin '' (vide) signifie que la page d'accueil du blog sera accessible à /blog/, puisque le préfixe blog/ est défini dans monprojet/urls.py.
5
Lancer le serveur et tester
Voir la page générée par l'IA s'afficher dans le navigateur.
✓

Lance le serveur et ouvre la page blog dans le navigateur :

Terminal — avec (env) actif 
python manage.py runserver
http://127.0.0.1:8000/blog/

Tu dois voir la page d'accueil HTML générée par l'IA — le titre "Mon Blog" et le message de bienvenue.

🚨Erreur TemplateDoesNotExist ? Le fichier HTML n'est pas au bon endroit. Vérifie que le chemin est exactement blog/templates/blog/index.html — pas blog/templates/index.html.
⚠️Erreur NoReverseMatch ou 404 ? La route n'est pas reliée. Vérifie que path('', views.index, ...) est dans blog/urls.py et que include('blog.urls') est dans monprojet/urls.py.
6
Améliorer le CSS avec l'IA
Appliquer le cycle vibe coding : décrire → générer → intégrer → tester.
✓

La page s'affiche mais elle est sans style. Utilise l'IA pour générer un CSS minimal :

💬 Prompt — CSS minimal
Génère un CSS minimal pour blog/static/blog/css/style.css. Police propre, fond clair, largeur max 700px centrée, titre h1 en couleur foncée, paragraphe lisible. Rien de complexe — juste du propre.

Colle le CSS généré dans blog/static/blog/css/style.css et recharge la page.

🎉Tu as appliqué le cycle complet du vibe coding — contexte → prompt → code généré → lecture → intégration → test. C'est exactement cette boucle qui t'accompagnera sur tous les prochains projets Django.
