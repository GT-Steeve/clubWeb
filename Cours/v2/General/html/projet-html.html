🌐 Projet — Ma première page HTML

Construis une page HTML propre sur le sujet de ton choix — la structure et l'imbrication sont la vraie priorité.

HTML Léger CSS Structure Imbrication
🎯
Objectif du projet

Tu vas créer une page HTML complète sur un sujet qui te plaît. L'objectif principal n'est pas le rendu visuel — c'est la qualité de la structure HTML : les bonnes balises, au bon endroit, bien imbriquées, avec une mise en forme du code lisible.

Un léger CSS est autorisé pour les couleurs uniquement (fond, texte, titres). Pas de mise en page complexe pour l'instant — ce sera le prochain projet.

⚠️ L'imbrication, c'est la règle des poupées russes : la dernière balise ouverte est la première à fermer. Une balise mal fermée peut casser toute la page. Utilise Shift+Alt+F dans VS Code pour formater et vérifier l'indentation.
💡
Idées de sujets — choisis ce qui te motive

N'importe quel sujet fonctionne. Ce qui compte, c'est d'avoir assez de contenu pour utiliser plusieurs types de balises :

🎮 Jeu vidéo favori
Présentation du jeu, histoire, personnages, conseils pour débuter.
🎵 Artiste ou groupe
Biographie, discographie, chansons préférées, liens.
🍕 Recette de cuisine
Ingrédients en liste, étapes numérotées, astuces du chef.
🐾 Animal ou sport
Faits intéressants, caractéristiques, images, pourquoi tu aimes ça.
🌍 Pays ou ville
Culture, gastronomie, monuments, langue — une page encyclopédique.
🧑‍💻 Présentation de toi
Qui tu es, ce que tu aimes, tes projets, tes passions — ton mini portfolio.
🏗️
Structure HTML attendue

Ta page doit respecter l'ordre suivant et utiliser ces types de balises :

<!DOCTYPE html>
<html lang="fr">
<head> — titre, charset, meta viewport
<body>
<header> — titre h1 + sous-titre
<main>
<h2> — titre de section
<p> — paragraphes
<ul> <li> — listes
<img> — avec src + alt
<a> — lien vers l'extérieur
</main>
<footer> — mention, auteur
</body>
</html>
💡 Utilise Shift+Alt+F dans VS Code après chaque section pour formater le code et vérifier l'indentation. Un code bien indenté révèle immédiatement les erreurs d'imbrication.
📋
Cahier des charges — Exigences obligatoires
✅ Un fichier index.html valide avec <!DOCTYPE html>, <html>, <head>, <body>.
✅ Un <header> avec un <h1> clair et un sous-titre en <p>.
✅ Un <main> contenant au moins 2 sections avec chacune un <h2> et des paragraphes.
✅ Au moins une liste (<ul> ou <ol>) avec plusieurs <li>.
✅ Au moins une image (<img>) avec les attributs src et alt remplis.
✅ Au moins un lien (<a href="...">) vers une source externe.
✅ Un <footer> avec ton prénom et l'année.
✅ CSS limité aux couleurs uniquement : fond de page, couleur du texte, couleur des titres — dans une balise <style> dans le <head>.
✅ Le code est correctement indenté et lisible (Shift+Alt+F pour formatter).
⭐
Points bonus
🌟 Utiliser <strong> et <em> pour mettre en valeur des mots importants dans tes paragraphes.
🌟 Ajouter une <ol> (liste numérotée) pour un classement ou une série d'étapes.
🌟 Utiliser un <hr> comme séparateur visuel entre deux sections.
🌟 Ajouter un attribut title sur les liens pour donner une info supplémentaire au survol.
🌟 Utiliser <h3> à l'intérieur d'une section pour créer une hiérarchie de titres à 3 niveaux.
🚀
Comment réaliser ce projet
1
Choisis ton sujet et liste mentalement tout ce que tu veux dire dessus : les sections, le contenu, les listes.
2
Crée le fichier index.html dans un nouveau dossier. Tape ! + Entrée dans VS Code pour le squelette de base.
3
Construis le squelette HTML d'abord : <header>, <main>, <footer> vides. Vérifie l'imbrication avant d'ajouter du contenu.
4
Remplis le contenu section par section — <h2>, <p>, <ul>. Formate (Shift+Alt+F) après chaque section.
5
Ajoute l'image et le lien. Assure-toi que l'image a un alt descriptif (pas juste "image").
6
Ajoute le CSS couleurs dans un <style> dans le <head> : 3 règles maximum (body, h1/h2, éventuellement a).
7
Ouvre dans le navigateur et vérifie que tout s'affiche correctement. Fais une dernière passe de formatage.
✅

La structure HTML, c'est la fondation de tout. Un code propre aujourd'hui = moins de bugs demain.
