🗺️
Le web a évolué en trois grandes ères

Internet existe depuis les années 1990. En trente ans, il a radicalement changé de nature. On ne l'utilise plus de la même façon, on n'y joue plus le même rôle — et sa structure même est en train de se transformer.

Pour comprendre où en est le web aujourd'hui et vers quoi il se dirige, il faut connaître ces trois grandes phases : le Web 1, le Web 2 et le Web 3. Chacun correspond à une époque, une philosophie, et une relation différente entre l'utilisateur et l'information.

🌐 Web 1 — Le web statique
Web 1
Le web "lecture seule"
Le web statique
🕐 Période : ~1990 → début des années 2000
Les sites web sont simples, souvent codés uniquement en HTML, sans interaction possible.
L'utilisateur est passif : il consulte des pages, lit du contenu, mais ne peut presque pas participer.
Les pages sont fixes — elles ne changent que si le développeur les modifie manuellement.
Pas de compte utilisateur, pas de commentaires, pas de partage — juste du contenu à consulter.
💡 Exemples concrets
Pages personnelles de l'époque, annuaires en ligne (Yahoo! directory), sites vitrines d'entreprises, encyclopédies statiques.
➡️ Tu consommes l'information. Point. Tu lis, tu navigues — mais tu ne laisses aucune trace, tu ne crées rien.
🌐 Web 2 — Le web social
Web 2
Le web "participatif"
Le web social
🕐 Période : ~2004 → aujourd'hui
Les utilisateurs peuvent désormais créer, publier, partager et interagir avec le contenu.
Explosion des réseaux sociaux, des blogs, des forums et des plateformes collaboratives.
Les sites sont dynamiques : le contenu change en temps réel selon les utilisateurs.
Mais toute cette activité passe par des plateformes centralisées qui détiennent les données.
💡 Exemples concrets
Facebook, YouTube, Instagram, Wikipedia, Twitter/X, Reddit, TikTok, Google Docs — tu crées du contenu, mais il appartient à la plateforme.
➡️ Tu crées et échanges du contenu — mais via des plateformes centralisées qui possèdent tes données et en tirent profit.
⚠️
Le revers du Web 2 — la centralisation

Le Web 2 a été une révolution. Mais il a aussi créé un problème majeur : quelques géants du numérique (Google, Meta, Amazon, Apple) concentrent une quantité colossale de données et de pouvoir.

Ce que ça signifie concrètement
🔒 Tes photos, tes messages, ton historique appartiennent à la plateforme, pas à toi.
🎯 Tes données sont analysées pour te cibler avec de la publicité.
🚫 Un compte peut être suspendu du jour au lendemain, sans recours.
💸 Les créateurs de contenu sont rémunérés selon les règles de la plateforme.
💡 La formule souvent citée : "Si c'est gratuit, c'est toi le produit." Sur les plateformes Web 2, tu ne paies pas — mais tu fournis tes données en échange du service.
🌐 Web 3 — Le web décentralisé
Web 3
Le web "décentralisé"
Le web de la propriété
🕐 Période : années 2020+ (en développement)
Basé sur la blockchain — une technologie de registre distribué, sans autorité centrale.
Les utilisateurs peuvent posséder leurs données et leurs actifs numériques sans intermédiaire.
Les transactions et les règles sont automatisées par des smart contracts (contrats autonomes).
Le Web 3 est encore en cours de construction — beaucoup de promesses, beaucoup de débats.
💡 Concepts clés du Web 3
Bitcoin · Ethereum · NFT · Smart contracts · DeFi · DAO · Wallets crypto · Métavers décentralisé
➡️ Tu contrôles tes données et tes biens numériques sans passer par un intermédiaire (banque, plateforme, gouvernement).
🔑
Les concepts clés du Web 3 — expliqués simplement
🔗 Blockchain
Un registre numérique partagé sur des milliers d'ordinateurs. Personne ne le contrôle seul — tout le monde peut le vérifier.
₿ Bitcoin
La première crypto-monnaie. Une monnaie numérique décentralisée — sans banque, sans État.
⟠ Ethereum
Une blockchain programmable. Permet de créer des applications décentralisées (dApps) et des smart contracts.
📜 Smart contract
Un programme autonome sur la blockchain. Il s'exécute automatiquement quand les conditions sont remplies — sans intermédiaire.
🖼️ NFT
Non-Fungible Token. Un certificat de propriété numérique unique, stocké sur la blockchain. Peut représenter une image, une musique, un objet.
🏛️ DeFi
Finance décentralisée. Des services financiers (prêts, échanges) sans banque, gérés par des smart contracts.
⚠️ Le Web 3 est porteur de vraies innovations — mais aussi de spéculations, d'arnaques et de promesses non tenues. Comme toute technologie émergente, il faut l'aborder avec curiosité et esprit critique.
