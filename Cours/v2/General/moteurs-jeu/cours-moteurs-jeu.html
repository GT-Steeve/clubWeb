Section 1
⚙️
Qu'est-ce qu'un moteur de jeu ?

Un moteur de jeu (game engine) est une boîte à outils complète qui prend en charge toutes les parties techniques d'un jeu — pour que le développeur puisse se concentrer sur le contenu et le gameplay.

Sans moteur, tu devrais tout coder toi-même : afficher un pixel à l'écran, calculer si deux objets se touchent, jouer un son, charger une texture. Avec un moteur, tout ça est déjà fait.

Ce qu'un moteur contient en général :

🖼️ Rendu
Affiche les graphismes 2D ou 3D sur l'écran (OpenGL, DirectX, Vulkan).
⚡ Physique
Simule gravité, collisions, rebonds, forces entre objets.
🔊 Audio
Lecture de sons, musiques spatiales 3D, effets.
📜 Scripting
Couche de programmation (C++, C#, GDScript…) pour la logique du jeu.
🗂️ Éditeur
Interface visuelle pour placer des objets, configurer des scènes.
📦 Export
Compilateur vers PC, console, mobile, web…
💡
Le canvas HTML5 que tu as appris, c'est en fait la base la plus minimale d'un moteur de jeu : une boucle, un contexte de dessin, un gestionnaire d'entrées. Les vrais moteurs font ça à une échelle industrielle.
Section 2
🎮
Unreal Engine

Unreal Engine est développé par Epic Games (créateur de Fortnite) depuis 1998. C'est le moteur de référence pour les jeux AAA — les productions à très gros budget avec des graphismes photoréalistes.

⚡
Unreal Engine 5
Epic Games · depuis 1998 · C++ + Blueprints
Lumen — système d'éclairage global entièrement dynamique (ombre, reflets en temps réel)
Nanite — géométrie virtualisée : des milliards de polygones sans sacrifier les performances
Blueprints — scripting visuel sans écrire de code (nœuds reliés entre eux)

Fortnite Star Wars Jedi: Survivor Hellblade II STALKER 2 Palworld
Points forts
Graphismes exceptionnels, Blueprints pour non-programmeurs, pipeline AAA, gratuit jusqu'à 1 M$ de revenus.
Points faibles
Courbe d'apprentissage abrupte, projets très lourds (dizaines de Go), moins adapté aux petits jeux 2D.
💰
Gratuit jusqu'à 1 million de dollars de revenus générés par ton jeu. Au-delà, Epic prend 5 % des revenus. Pour un jeu indépendant, tu ne paieras probablement jamais.
Section 3
🔷
Unity

Unity est développé par Unity Technologies depuis 2005. C'est le moteur le plus populaire dans l'industrie indépendante et mobile. Son point fort : exporter le même jeu sur des dizaines de plateformes différentes.

🔷
Unity
Unity Technologies · depuis 2005 · C#
Cross-platform — iOS, Android, PC, Mac, Linux, PS5, Xbox, Nintendo Switch, WebGL…
Asset Store — marketplace d'assets (modèles 3D, sons, scripts) prêts à l'emploi
HDRP / URP — pipelines de rendu moderne (HDR haute fidélité ou Ultra légère)

Hollow Knight Cuphead Among Us Genshin Impact Cities: Skylines
Points forts
Communauté énorme, tons de tutoriels, excellent pour le mobile, très polyvalent en 2D et 3D.
Points faibles
Controverse tarifaire en 2023 (Runtime Fee révoquée après pression), certains bugs historiques persistants.
📌
En 2023, Unity a annoncé des frais à l'installation (Runtime Fee), puis a fait marche arrière face au tollé des développeurs. L'épisode a poussé beaucoup de studios indépendants vers Godot.
Section 4
🤖
Godot

Godot est un moteur 100 % open source créé en 2014 par Juan Linietsky et Ariel Manzur. Il est entièrement gratuit, sans aucune royalties, et appartient à la communauté via la Software Freedom Conservancy.

🤖
Godot Engine
Open Source · depuis 2014 · GDScript + C# + C++
GDScript — langage propre à Godot, syntaxe proche de Python, très simple à apprendre
Scènes & Nœuds — architecture unique : tout est une scène composée de nœuds (très logique pour un dev web)
Excellence 2D — le meilleur moteur open source pour les jeux 2D, pipeline dédié

Cassette Beasts Dome Keeper Brotato Hive Time The Mirror
Points forts
Entièrement gratuit (MIT), léger (moins de 100 Mo), superbe pour la 2D, aucune politique tarifaire surprise possible.
Points faibles
3D moins mature qu'Unreal ou Unity, GDScript peu utilisé hors Godot, communauté plus petite.
🌟
Depuis la controverse Unity, Godot a connu une croissance explosive. Le dépôt GitHub a gagné des dizaines de milliers d'étoiles en quelques jours. C'est aujourd'hui un choix sérieux pour les indépendants.

Section 6
🧭
Comment choisir ?

Il n'y a pas de "meilleur" moteur — il y a le moteur le plus adapté à ton projet, ton équipe et tes objectifs.

⚡ Unreal Engine Jeu 3D ambitieux
Effets photoréalistes
Équipe avec C++
🔷 Unity Jeu mobile
Multi-plateforme
Grande communauté
🤖 Godot Jeu 2D indie
Open source obligatoire
Débutant en moteur
🎯
Si tu débutes avec les moteurs de jeu, Godot est le meilleur point d'entrée : gratuit, léger, et sa logique de scènes ressemble beaucoup au DOM que tu connais déjà. Unity est le choix naturel si tu veux travailler dans l'industrie mobile.
