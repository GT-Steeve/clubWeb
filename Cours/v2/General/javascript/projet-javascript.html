🎮 Projet — Clicker Game

Crée ton premier jeu JavaScript : un clicker avec des paliers de déblocage.

index.html script.js style.css Paliers Vibe coding
Objectif : Créer un jeu clicker en 3 fichiers séparés (HTML, CSS, JS).
Mécaniques : +1 par clic · à 10 points un bouton +10 apparaît · à 100 points, utilise l'IA pour générer le bouton ×2.
🎮 Aperçu — voici ce que tu vas créer
Score : 0
Progression 0 / 6 étapes
1
Créer la structure HTML
▾

Crée un dossier clicker-game/ puis le fichier index.html. La structure HTML doit avoir un affichage du score, le bouton principal, et deux boutons cachés pour les paliers.

📁 Structure de fichiers à créer
clicker-game/ ├── index.html ← à créer maintenant ├── style.css ← étape 6 └── script.js ← étape 2
index.html
<!DOCTYPE html> <html lang="fr"> <head> <meta charset="UTF-8"> <title>Mon Clicker Game</title> <link rel="stylesheet" href="style.css"> </head> <body> <div id="jeu"> <h1 id="score-affiche">Score : 0</h1> <!-- Bouton principal : toujours visible --> <button id="btn-un">👆 +1 point</button> <!-- Palier 1 : caché par défaut, débloqué à 10 points --> <button id="btn-dix" style="display:none;">⚡ +10 points</button> <!-- Palier 2 : caché par défaut, débloqué à 100 points --> <button id="btn-x2" style="display:none;">✨ ×2</button> </div> <!-- Le script se charge à la fin du body --> <script src="script.js"></script> </body> </html>
💡
Les deux boutons de paliers ont style="display:none;" directement dans le HTML — ils sont invisibles au démarrage. C'est JavaScript qui les affichera au bon moment.
2
Créer script.js — les variables
▾

Crée le fichier script.js. Commence par déclarer les variables et sélectionner les éléments HTML. Ces éléments seront utilisés dans tout le reste du script.

script.js — début du fichier
// ═══ VARIABLES DU JEU ═══ let score = 0; // le score démarre à zéro // ═══ SÉLECTION DES ÉLÉMENTS HTML ═══ const affichage = document.getElementById('score-affiche'); const btnUn = document.getElementById('btn-un'); const btnDix = document.getElementById('btn-dix'); const btnX2 = document.getElementById('btn-x2');
🔗
On sélectionne tous les éléments une seule fois en haut du fichier et on les stocke dans des const. C'est plus efficace que de les chercher à chaque clic.
3
Le bouton +1 — événement & affichage
▾

Ajoute un écouteur d'événement sur le bouton principal. À chaque clic, on incrémente le score et on met à jour le texte affiché.

script.js — ajouter après les variables
// ═══ BOUTON +1 ═══ btnUn.addEventListener('click', function() { score += 1; affichage.textContent = "Score : " + score; verifierPaliers(); // on vérifie les paliers à chaque clic });
La fonction verifierPaliers — à ajouter
// ═══ VÉRIFIER LES PALIERS ═══ function verifierPaliers() { // Palier 1 : débloquer +10 à 10 points if (score >= 10) { btnDix.style.display = 'inline-block'; } // Palier 2 : débloquer ×2 à 100 points (à compléter étape 5) if (score >= 100) { btnX2.style.display = 'inline-block'; } }
💡
On regroupe toute la logique de déblocage dans une seule fonction verifierPaliers(). Elle sera appelée après chaque clic — sur tous les boutons. C'est plus propre que de dupliquer le code.
🧪
Ouvre index.html dans ton navigateur (double-clic ou Live Server). Clique 10 fois — le bouton +10 doit apparaître. Ouvre F12 → Console pour voir d'éventuelles erreurs.
4
Le bouton +10 — même logique
▾

Le bouton +10 fonctionne exactement comme le +1 — mais il ajoute 10 au score. On appelle aussi verifierPaliers() pour détecter le palier suivant.

script.js — ajouter après le bouton +1
// ═══ BOUTON +10 ═══ btnDix.addEventListener('click', function() { score += 10; affichage.textContent = "Score : " + score; verifierPaliers(); });
🔍
Remarque comme le code est presque identique au bouton +1 — seul le 10 change. C'est l'occasion de voir qu'on pourrait créer une fonction générique ajouterPoints(n). Mais pour l'instant, la duplication est parfaitement acceptable.
🧪
Teste : clique sur +1 jusqu'à 10 → le bouton +10 apparaît → clique sur +10 jusqu'à 100 → le bouton ×2 doit apparaître (même s'il ne fait encore rien).
5
Le bouton ×2 — avec l'aide de l'IA
▾

Le bouton ×2 multiplie le score actuel par 2 puis le remet à jour. Utilise l'IA pour générer ce code — mais lis et comprends ce qu'elle produit avant de le coller.

🤖 Prompt à envoyer à l'IA
J'ai un jeu clicker JavaScript. Le score est stocké dans une variable `let score`. L'affichage est un élément HTML avec l'id "score-affiche". Le bouton ×2 a l'id "btn-x2" et est déjà sélectionné dans une const `btnX2`. Écris le code JavaScript pour que ce bouton : 1. Multiplie le score par 2 quand on clique 2. Mette à jour l'affichage avec "Score : " + score 3. Appelle la fonction verifierPaliers() après Juste le bloc addEventListener, pas de HTML.
Résultat attendu de l'IA — à intégrer dans script.js
// ═══ BOUTON ×2 ═══ btnX2.addEventListener('click', function() { score = score * 2; affichage.textContent = "Score : " + score; verifierPaliers(); });
🔬
Avant de coller le code de l'IA, vérifie : les noms de variables correspondent aux tiens (score, affichage, btnX2) ? La logique est correcte ? L'IA peut se tromper — relis toujours.
⚠️
Si l'IA génère du code différent (avec une fonction fléchée, ou d'autres variables), assure-toi que ça correspond à ta structure. Ajuste si nécessaire.
6
Ajouter style.css
▾

Crée le fichier style.css. Chaque bouton a une couleur différente pour indiquer son niveau de puissance.

🤖 Prompt IA pour le CSS
J'ai un jeu clicker HTML avec : - Un div#jeu qui contient tout - Un h1#score-affiche (affichage du score) - Un button#btn-un (bouton +1, toujours visible) - Un button#btn-dix (bouton +10, débloqué) - Un button#btn-x2 (bouton ×2, débloqué) Crée un style.css simple pour un jeu avec fond sombre (#1a1a2e), le score en grand et en jaune, les boutons arrondis avec des couleurs différentes : jaune pour +1, bleu pour +10, violet pour ×2.
style.css — exemple de base (à personnaliser)
body { background: #1a1a2e; display: flex; justify-content: center; align-items: center; min-height: 100vh; font-family: 'Arial', sans-serif; } #jeu { text-align: center; } #score-affiche { color: #EAB308; font-size: 3rem; margin-bottom: 2rem; } button { border: none; border-radius: 12px; padding: 14px 28px; font-size: 1rem; font-weight: 700; cursor: pointer; margin: 8px; transition: transform 0.1s; } button:active { transform: scale(0.95); } #btn-un { background: #EAB308; color: #1C1C1C; } #btn-dix { background: #3B82F6; color: #ffffff; } #btn-x2 { background: #8B5CF6; color: #ffffff; }
🎨
Personnalise librement — change les couleurs, ajoute une animation :hover, un compteur de clics, un affichage du "palier actuel"… Le jeu de base est prêt, enrichis-le !
💡 Pour aller plus loin

Ton jeu fonctionne ? C'est maintenant que ça devient intéressant. Voici des idées pour l'enrichir — dans l'ordre que tu veux, à ton rythme. Pour chacune, un prompt IA est prêt à copier-coller.

🎆
Feu d'artifice au million de points
Déclenche une pluie de confettis quand le joueur dépasse 1 000 000 points. Un moment de célébration bien mérité !
🤖 Prompt IA suggéré
Dans mon clicker game JS, j'ai une variable score et une fonction verifierPaliers(). Ajoute un effet de confettis qui se déclenche une seule fois quand score dépasse 1 000 000. Utilise la librairie canvas-confetti (CDN). Montre-moi où l'intégrer dans mon code existant.
🎯
Objectif personnalisé
Ajoute un champ de saisie pour que le joueur fixe lui-même son objectif. Affiche une barre de progression vers cet objectif et un message de victoire quand il l'atteint.
🤖 Prompt IA suggéré
Dans mon clicker game, ajoute un champ HTML (input number) pour que le joueur entre son objectif de score. Affiche une barre de progression qui se remplit au fur et à mesure. Quand l'objectif est atteint, affiche un message de victoire et désactive tous les boutons.
➕
Ajouter ou supprimer des boutons
Ajoute un bouton +1 000 qui se débloque à 500 points. Ou fais disparaître le +1 une fois le +10 débloqué pour forcer le joueur à progresser. C'est toi qui choisis les règles.
🤖 Prompt IA suggéré
Dans mon verifierPaliers(), ajoute : - Un bouton +1 000 (id="btn-mille") qui apparaît à 500 points - Le bouton +1 disparaît (style.display='none') quand score atteint 50 pour obliger le joueur à utiliser le +10 Montre-moi le HTML du bouton et les changements dans verifierPaliers().
🐢
Ralentir les gains
Ajoute un délai entre les clics (cooldown), ou fais que chaque bouton coûte des points pour être utilisé. Ça crée un vrai équilibre de jeu et force le joueur à réfléchir à sa stratégie.
🤖 Prompt IA suggéré
Dans mon clicker game, ajoute un cooldown de 0.5 secondes sur le bouton +1 : après chaque clic, le bouton devient désactivé (disabled) pendant 500ms puis se réactive. Montre-moi comment faire avec setTimeout et button.disabled.
