🐘 PHP & Frameworks

Le langage qui fait tourner 80% des sites web — et ses frameworks.

Serveur PHP Symfony · Laravel WordPress · Drupal
1
Qu'est-ce que PHP ?

PHP (Hypertext Preprocessor) est un langage de programmation côté serveur. Contrairement au HTML ou au JavaScript front-end, PHP s'exécute sur le serveur avant d'envoyer la page au navigateur.

Créé en 1994 par Rasmus Lerdorf, PHP est aujourd'hui présent sur plus de 77% des sites web — dont WordPress, Facebook à ses débuts, Wikipedia. C'est le langage du web dynamique par excellence.

🌐 HTML/CSS/JS (front) S'exécute dans le navigateur de l'utilisateur. Le code est visible dans "Afficher la source".
🐘 PHP (back) S'exécute sur le serveur. L'utilisateur ne voit jamais le code PHP — seulement le HTML qu'il génère.
Ce que PHP peut faire
🗄️ Lire et écrire dans une base de données
👤 Gérer les comptes utilisateurs et les sessions
📧 Envoyer des emails depuis un formulaire
🔒 Sécuriser les données (hash de mots de passe…)
📄 Générer du HTML dynamique selon l'utilisateur
📝 Syntaxe PHP de base
2
La syntaxe PHP — les fondamentaux

Le code PHP s'écrit dans des fichiers .php et s'intègre dans du HTML grâce aux balises <?php et ?>.

<!-- Fichier: index.php --> <?php // Variables — toujours préfixées par $ $prenom = "Alice"; $age = 28; $actif = true; // Afficher du contenu echo "Bonjour " . $prenom; // concaténation avec . echo "<br>"; // Condition if ($age >= 18) { echo "Majeur"; } else { echo "Mineur"; } ?> <!-- Mélanger PHP et HTML --> <h1>Bienvenue, <?php echo $prenom; ?> !</h1>

PHP et les formulaires — le cas concret

L'usage le plus courant de PHP : récupérer les données d'un formulaire HTML et les traiter côté serveur.

<!-- formulaire.html --> <form action="traitement.php" method="POST"> <input type="text" name="prenom" placeholder="Ton prénom"> <input type="email" name="email"> <button type="submit">Envoyer</button> </form> // traitement.php <?php // Récupérer les données POST $prenom = htmlspecialchars($_POST["prenom"]); $email = htmlspecialchars($_POST["email"]); // Toujours valider et sécuriser les données ! if (!empty($prenom) && filter_var($email, FILTER_VALIDATE_EMAIL)) { echo "Bienvenue, " . $prenom . " !"; } else { echo "Données invalides."; } ?>
⚠️ htmlspecialchars() est essentiel — il protège contre les attaques XSS en transformant les caractères dangereux. Ne jamais afficher directement une donnée utilisateur sans la nettoyer.
🏗️ Les frameworks PHP
5
Pourquoi utiliser un framework ?

Un framework est une boîte à outils structurée qui impose une façon d'organiser le code et fournit des fonctionnalités prêtes à l'emploi. Il évite de réinventer la roue à chaque projet.

❌ PHP sans framework Code répétitif, sécurité à gérer manuellement, structure anarchique, difficile à maintenir en équipe.
✅ PHP avec framework Structure MVC claire, sécurité intégrée, ORM pour la BDD, communauté et documentation riches.
📌 La plupart des frameworks PHP utilisent le pattern MVC (Model-View-Controller) : le Modèle gère les données, la Vue affiche l'interface, le Contrôleur fait le lien entre les deux.
6
Symfony — le framework professionnel

Créé en 2005 par SensioLabs (français 🇫🇷), Symfony est le framework PHP de référence dans le monde professionnel. Modulaire, robuste et utilisé pour des projets d'envergure.

Points clés de Symfony
🧩 Composants réutilisables — plus de 50 composants indépendants (Routing, Security, Cache…)
🔁 Doctrine ORM — manipule la base de données via des objets PHP (plus de SQL brut)
🛡️ Sécurité intégrée — gestion des rôles, firewall, CSRF…
🧪 Tests — PHPUnit intégré pour tester son code
📦 Bundles — des extensions pour ajouter des fonctionnalités
// Exemple : un contrôleur Symfony simple use Symfony\Bundle\FrameworkBundle\Controller\AbstractController; use Symfony\Component\Routing\Annotation\Route; class ArticleController extends AbstractController { // La route /articles appelle cette méthode #[Route('/articles', name: 'article_list')] public function index(): Response { $articles = $this->getDoctrine() ->getRepository(Article::class) ->findAll(); return $this->render('article/index.html.twig', [ 'articles' => $articles, ]); } }
🎯 Symfony est idéal pour les grandes applications d'entreprise. Sa courbe d'apprentissage est plus raide — mais il offre une architecture solide et maintenable sur le long terme.
7
Laravel — le framework élégant

Créé en 2011 par Taylor Otwell, Laravel est le framework PHP le plus populaire aujourd'hui. Il est connu pour sa syntaxe expressive et sa courbe d'apprentissage plus douce que Symfony.

Points clés de Laravel
✨ Eloquent ORM — manipulation de la BDD intuitive et expressive
🔀 Blade — moteur de templates simple et puissant
🚀 Artisan — outil en ligne de commande pour générer du code
📬 Queues & Jobs — tâches asynchrones intégrées
🔐 Authentification prête — système de login en quelques commandes
// Eloquent ORM — la même requête qu'en SQL, mais en PHP // SQL : SELECT * FROM users WHERE active = 1 ORDER BY name $users = User::where('active', 1) ->orderBy('name') ->get(); // Route Laravel simple Route::get('/articles', function() { $articles = Article::all(); return view('articles.index', ['articles' => $articles]); }); // Commandes Artisan (terminal) // php artisan make:model Article -m → crée le modèle + migration BDD // php artisan serve → lance le serveur local
📦 Les CMS PHP — WordPress & Drupal
8
WordPress — le CMS dominant

WordPress n'est pas un framework mais un CMS (Content Management System) — un système de gestion de contenu. Créé en 2003, il propulse aujourd'hui 43% de tous les sites web. C'est un outil, pas un langage — on l'installe, on le configure, on l'étend avec des thèmes et plugins.

✅ WordPress est parfait pour Blogs, sites vitrines, e-commerce (WooCommerce), portfolios. Prise en main rapide, milliers de thèmes et plugins disponibles.
❌ WordPress est limité pour Applications web complexes, fonctionnalités très spécifiques, haute performance, architecture sur-mesure.
L'écosystème WordPress
🎨 Thèmes — l'apparence du site (Astra, Divi, Elementor…)
🔌 Plugins — ajout de fonctionnalités (formulaires, SEO, e-commerce…)
📝 Gutenberg — éditeur de contenu par blocs intégré
🛒 WooCommerce — transforme WordPress en boutique en ligne
9
Drupal — le CMS des grandes organisations

Drupal est un CMS open source plus technique que WordPress, conçu pour des projets complexes à grande échelle. Il est utilisé par des gouvernements, universités et grandes entreprises.

🏛️ Drupal excelle pour Sites gouvernementaux, portails d'entreprise, gestion de contenu multilingue complexe, sécurité critique.
📉 Drupal est moins adapté pour Projets simples et rapides, équipes sans développeurs PHP expérimentés, petits budgets.
