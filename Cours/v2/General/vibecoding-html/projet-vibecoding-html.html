🎨 Projet — Mon site web par vibe coding

Crée un vrai site HTML/CSS/JS sur le sujet de ton choix — et sois capable d'expliquer comment il fonctionne !

HTML CSS JavaScript Projet libre Vibe Coding
🎯
Objectif du projet

Tu vas créer un vrai site web sur un sujet qui te motive — un portfolio, une page fan, un quiz, une landing page, un mini-blog. Peu importe le thème, tant que le site est complet, fonctionnel et que tu peux expliquer son fonctionnement.

L'IA t'aide à coder — c'est autorisé et encouragé. Mais tu dois être capable de lire le code généré, d'expliquer le rôle de chaque partie (HTML structure, CSS style, JS comportement), et de faire des modifications toi-même.

⚠️ Coller du code sans le lire, c'est l'effet spaghetti en action. Pour chaque bloc généré par l'IA, pose-toi la question : "Qu'est-ce que ce code fait exactement ?" Si tu ne peux pas répondre, demande à l'IA de te l'expliquer avant de continuer.
💡
Idées de sujets — choisis ce qui te motive

Ton sujet peut être n'importe quoi. Voici des idées pour t'inspirer :

🧑‍💻 Portfolio personnel
Présente-toi : qui tu es, tes projets, tes compétences, un formulaire de contact.
🎮 Page fan / univers
Un jeu, un film, une série, un artiste — présente l'univers que tu aimes.
❓ Quiz interactif
Questions + réponses, score final, feedback. Thème libre (sport, culture, jeux…).
🛍️ Landing page produit
Présente un produit fictif ou réel : hero, features, CTA, section prix.
📋 Tableau de bord
Météo, tâches à faire, planning, calculatrice — une page utile au quotidien.
✍️ Mini-blog
Articles, catégories, pagination simulée — un site de lecture en HTML statique.
🏗️
Les 3 couches obligatoires

Ton site doit utiliser les trois langages du cours, chacun dans son rôle :

🏗️
HTML — La structure. Balises sémantiques (<header>, <section>, <article>…), contenu bien organisé, images avec alt.
🎨
CSS — Le style. Mise en page (Flexbox ou Grid), couleurs, typographie, responsive. Fichier style.css séparé de l'HTML.
⚡
JavaScript — Le comportement. Au minimum une interaction : menu hamburger, quiz, modal, filtre de contenu, animation au clic… Fichier script.js séparé.
🗣️
L'explication — la vraie épreuve

Créer le site est la première moitié du projet. La deuxième : être capable de l'expliquer. Pour chaque partie de ton site, tu dois pouvoir répondre à ces questions :

Questions à savoir répondre sur ton site :
1.Quel est le rôle de chaque fichier ? (index.html, style.css, script.js)
2.Quelle balise HTML est utilisée pour la navigation principale et pourquoi ?
3.Comment fonctionne ta mise en page ? (Flexbox ? Grid ? Explique le principe.)
4.Quelle interaction JavaScript as-tu ajoutée ? Que se passe-t-il quand l'utilisateur interagit ?
5.Si tu changes une couleur dans le CSS, quel fichier tu modifies et où exactement ?
6.Si tu veux ajouter une nouvelle section au site, quelle est la première chose que tu fais ?
🧠 Tu n'as pas besoin d'avoir tout codé toi-même pour expliquer. Mais tu dois avoir lu et compris chaque ligne. Si l'IA a généré une fonction JS, tu dois savoir ce qu'elle fait — même si tu n'aurais pas su l'écrire seul.
📋
Cahier des charges — Exigences obligatoires
✅ Le site s'ouvre dans le navigateur sans erreur (aucun lien cassé, aucune image manquante).
✅ 3 fichiers séparés : index.html, style.css, script.js — liés correctement.
✅ Le HTML utilise des balises sémantiques (<header>, <main>, <section>, <footer>…), pas uniquement des <div>.
✅ Le CSS assure une mise en page lisible sur ordinateur (Flexbox ou Grid, au choix).
✅ Le JavaScript ajoute au moins une interaction fonctionnelle visible pour l'utilisateur.
✅ Tu es capable de répondre aux 6 questions d'explication ci-dessus sur ton propre site.
⭐
Points bonus
🌟 Le site est responsive : il s'adapte correctement sur mobile (media queries CSS).
🌟 Appliquer l'architecture du cours Architecture : dossiers css/, js/, img/ avec les bons chemins relatifs.
🌟 Ajouter une 2e interaction JS : animation, filtre, dark mode, localStorage pour mémoriser une préférence…
🌟 Publier le site sur GitHub Pages et partager le lien (cours GitHub Pages disponible dans le sommaire).
🌟 Utiliser des variables CSS (:root { --couleur-principale: … }) pour centraliser la palette de couleurs.
🚀
Comment réaliser ce projet
1
Choisis ton sujet — Prends quelque chose qui te motive vraiment. Un projet ennuyeux avance 3× plus lentement.
2
Dessine les sections — Sur papier ou dans ta tête : header, hero, section principale, footer. Décide du contenu de chaque partie avant de coder.
3
Crée la structure HTML d'abord — Toutes les sections en HTML vide avant de toucher au CSS. Vérifie dans le navigateur que la structure est logique. Ensuite seulement, passe au style.
4
Demande à l'IA des blocs précis — Pas « fais mon site ». Mais « génère le CSS de ma navbar avec Flexbox, logo à gauche, liens à droite, fond sombre ». Un bloc à la fois, lu et compris avant de passer au suivant.
5
Ajoute le JavaScript en dernier — Une fois que l'HTML et le CSS sont stables. Décris précisément l'interaction voulue, lis la fonction générée, teste-la, comprends-la.
6
Prépare ton explication — Avant de déclarer le projet terminé, réponds aux 6 questions de la section "L'explication". Si tu bloques sur une question, relis le code concerné jusqu'à comprendre.
