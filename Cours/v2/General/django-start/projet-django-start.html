Objectif du projet

Tu vas créer un projet Django vierge fonctionnel, étape par étape, depuis la vérification de l'installation de Python jusqu'à l'affichage de la page de bienvenue Django dans ton navigateur.

Aucun template à copier-coller. Tu suis les étapes, tu lis les messages du terminal, tu comprends ce que tu fais.

Progression 0 / 6 étapes
1
Vérifier les prérequis
Python installé ? pip disponible ? On vérifie avant tout.
✓

Avant d'installer Django, assure-toi que Python est bien installé sur ta machine. Ouvre un terminal (PowerShell sur Windows, Terminal sur Mac/Linux) et tape ces commandes :

Terminal 
# Vérifier la version de Python (doit afficher 3.10 ou plus)
python --version

# Si la commande n'est pas trouvée, essaie :
python3 --version

# Vérifier que pip est disponible
pip --version
Résultat attendu
Python 3.12.2 pip 24.0 from C:\...\pip (python 3.12)
🚨 Python non trouvé ? Télécharge Python depuis python.org et coche bien "Add Python to PATH" lors de l'installation. Relance ensuite le terminal.
2
Créer un environnement virtuel
Un espace isolé pour le projet — jamais d'installation globale.
✓

L'environnement virtuel (venv) réserve un espace privé pour ton projet. Django et toutes ses dépendances s'installent dedans, sans polluer le reste de ta machine.

Terminal — dans ton dossier de projets 
# Crée un dossier pour le projet
mkdir monprojet-django
cd monprojet-django

# Crée l'environnement virtuel dans un dossier "env"
python -m venv env
📁 Un dossier env/ vient d'apparaître dans ton dossier. C'est ton environnement isolé. Tu ne touches jamais à son contenu manuellement.
3
Activer l'environnement virtuel & installer Django
Sans activation, pip installe Django au mauvais endroit.
✓

L'activation "entre" dans l'environnement virtuel. Tout ce que tu installes ensuite avec pip ira dans env/ et uniquement là.

Windows (PowerShell) 
.\env\Scripts\activate
macOS / Linux 
source env/bin/activate
Comment savoir si l'environnement est actif ?
(env) user@machine monprojet-django %

Le préfixe (env) à gauche du terminal confirme que tu es dans l'environnement. Maintenant, installe Django :

Terminal — avec (env) actif 
pip install django

# Vérifie l'installation
django-admin --version
Résultat attendu
Collecting django Downloading Django-5.x.x-py3-none-any.whl ... Successfully installed django-5.x.x 5.x.x
🚨 Tu ne vois pas (env) ? L'environnement n'est pas activé. Relance la commande d'activation avant de faire pip install django.
4
Créer le projet Django
Une commande génère toute la structure du projet.
✓

La commande django-admin startproject génère automatiquement la structure de base du projet. Le point . à la fin évite de créer un sous-dossier en double.

Terminal — avec (env) actif, dans monprojet-django/ 
# Crée le projet dans le dossier courant
django-admin startproject monsite .
Structure générée
monprojet-django/
├── env/                 # Ton environnement virtuel
├── monsite/
│   ├── __init__.py
│   ├── settings.py      # Configuration du projet
│   ├── urls.py          # Routes principales
│   ├── asgi.py
│   └── wsgi.py
└── manage.py            # Commande centrale de Django
📌 manage.py est ton outil principal. C'est lui que tu utiliseras pour lancer le serveur, créer des apps, appliquer les migrations, etc.
5
Lancer le serveur de développement
Le serveur intégré de Django — uniquement en développement.
✓

Django inclut un serveur web de développement léger. Il suffit d'une commande pour le démarrer.

Terminal — avec (env) actif, dans monprojet-django/ 
python manage.py runserver
Résultat attendu dans le terminal
Watching for file changes with StatReloader Performing system checks... System check identified no issues (0 silenced). You have 18 unapplied migration(s)... May 17, 2026 - 10:42:15 Django version 5.x.x, using settings 'monsite.settings' Starting development server at http://127.0.0.1:8000/ Quit the server with CONTROL-C.
⚠️ Le message sur les migrations est normal à ce stade. Django te signale que les tables de sa base de données interne n'ont pas encore été créées. Ce n'est pas une erreur — ton serveur fonctionne quand même.
🚨 Erreur "That port is already in use" ? Un autre serveur tourne sur le port 8000. Lance sur un autre port : python manage.py runserver 8080
6
Ouvrir la page dans le navigateur
La fusée Django — preuve que tout fonctionne.
✓

Ouvre ton navigateur et va à l'adresse :

http://127.0.0.1:8000/
ou http://localhost:8000/

Tu dois voir la page de bienvenue de Django — une fusée verte sur fond noir avec le message "The install worked successfully! Congratulations!"

🎉 Tu vois la fusée ? Bravo — ton projet Django vierge est opérationnel. Le serveur tourne, le projet est créé, l'environnement virtuel est actif. Tu peux maintenant commencer à créer des apps avec python manage.py startapp.
🚨 Page inaccessible ? Vérifie que le terminal affiche bien "Starting development server at http://127.0.0.1:8000/" et que tu n'as pas fermé le terminal par erreur. Le serveur doit rester ouvert pendant que tu utilises le site.
📋
Ce qu'on doit voir à la fin
✅Le terminal affiche (env) avant le prompt — l'environnement virtuel est activé.
✅django-admin --version affiche un numéro de version sans erreur.
✅Le dossier monsite/ et le fichier manage.py existent dans le projet.
✅python manage.py runserver démarre sans erreur (les warnings migrations sont OK).
✅La page de bienvenue Django (la fusée) s'affiche sur http://127.0.0.1:8000/.
