💻 Projet — Mon guide VS Code

Crée ta notice personnelle de VS Code en format numérique !

Projet libre Guide personnel Format numérique VS Code
🎯
Objectif du projet

Tu connais maintenant VS Code — son interface, ses raccourcis, ses extensions, ses fonctionnalités clés. Maintenant tu vas créer ton propre guide personnel : une notice numérique que tu gardes à portée de main pour t'y référer quand tu en as besoin.

Ce n'est pas un résumé scolaire — c'est ta note personnelle, écrite à ta façon, avec les infos qui te sont vraiment utiles. Dans 6 mois, ce guide doit te permettre de retrouver en 30 secondes comment faire quelque chose dans VS Code.

💡 Un bon guide personnel, c'est celui que TU comprends rapidement. Utilise tes propres mots, tes propres raccourcis favoris, tes propres captures d'écran si tu veux. Fais-le à ton image !
📚
Contenu à inclure dans ton guide

Ton guide doit couvrir les thèmes essentiels du cours. Voici les sections recommandées — adapte-les à ta façon :

⬇️ Installation
Où télécharger, comment installer, pourquoi VS Code.
🖥️ L'interface
Explorateur, éditeur, terminal, barre de statut — chaque zone.
📂 Ouvrir un projet
Ouvrir un dossier, créer des fichiers, nommer avec l'extension.
⌨️ Raccourcis clés
Formater, commenter, dupliquer, chercher — les essentiels.
🔌 Extensions utiles
Prettier, Live Server, et celles que tu utilises.
💡 Astuces personnelles
Tes trucs découverts, tes raccourcis préférés, tes pièges à éviter.
📄
Format de ton guide

Ton guide peut prendre la forme qui te convient le mieux. Le seul critère : il doit être numérique et consultable facilement.

Formats acceptés
🌐 Page HTML 📕 PDF 📘 Word / .docx 📝 Markdown .md
💡 La page HTML est recommandée — tu peux y ajouter du CSS pour la rendre agréable, et même du JS pour des sections interactives. Mais si tu préfères Word ou un PDF bien structuré, c'est valide aussi !
💡 Pour créer un PDF depuis ta page HTML : ouvre-la dans le navigateur, fais Ctrl+P → "Enregistrer en PDF". C'est la méthode la plus simple !
📋
Cahier des charges — Exigences obligatoires

Peu importe le format choisi, ces points sont non-négociables :

✅ Le guide s'ouvre et est lisible sans erreur (dans un navigateur, Word, ou un lecteur PDF).
✅ Il couvre au moins 4 des 6 thèmes listés ci-dessus avec tes propres mots.
✅ Il est structuré : un titre principal, des sections séparées, du contenu lisible d'un coup d'œil.
✅ Les raccourcis clavier sont présents sous forme de tableau ou de liste claire (ex : Ctrl+S → Sauvegarder).
✅ Le contenu est rédigé par toi — ce n'est pas une copie du cours, c'est ton interprétation personnelle.
⭐
Points bonus — Pour aller plus loin

Ces éléments ne sont pas obligatoires mais enrichissent vraiment ton guide :

🌟 Créer ta page en HTML avec un fichier style.css séparé — et appliquer les bonnes conventions d'architecture de fichiers vues dans le cours Architecture !
🌟 Ajouter des captures d'écran annotées de l'interface VS Code pour illustrer chaque section.
🌟 Ajouter une section "Mes extensions installées" avec le nom, le rôle et pourquoi tu les as choisies.
🌟 Ajouter du JavaScript : un menu de navigation rapide vers chaque section, ou un mode sombre toggleable.
🌟 Exporter une version PDF de ta page HTML et l'inclure dans ton dossier de projet.
🚀
Comment réaliser ce projet
1
Relis le cours — Parcours cours-vscode.html et note les 6 thèmes. Pour chacun, écris 2-3 points clés à toi — les choses que tu retiens et qui te semblent importantes.
2
Choisis ton format — HTML pour la liberté maximale, Word ou PDF si tu préfères un format plus classique. Décide avant de commencer.
3
Structure d'abord — Crée la structure complète avant de remplir le contenu. Pour HTML : tous les titres de sections. Pour Word : tous les en-têtes. Ensuite seulement, tu remplis.
4
Ajoute le contenu à ta façon — Utilise tes mots, tes exemples, tes astuces personnelles. Inclus tes raccourcis préférés, les extensions que tu as installées, les erreurs que tu as faites.
5
Teste la lisibilité — Ouvre ton guide et imagine que tu l'utilises dans 6 mois. En 30 secondes, peux-tu trouver comment formater du code dans VS Code ? Si non, améliore la structure.
6
Utilise l'IA pour le style — Pour le CSS ou la mise en forme Word, demande de l'aide. Mais le contenu de ton guide, c'est toi qui le rédiges : "Comment faire un tableau de raccourcis en CSS ?" — ça c'est bien.
