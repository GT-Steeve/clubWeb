⌨️ Raccourcis clavier

Travaille 3× plus vite — sans toucher la souris.

Édition Sélection Navigateur VS Code
🎯
Pourquoi apprendre les raccourcis ?

Chaque fois que tu quittes le clavier pour attraper la souris, tu perds du temps. Ce geste semble anodin — mais répété des centaines de fois par jour, ça représente des heures perdues par semaine.

Les raccourcis clavier, c'est le premier réflexe d'un professionnel. Que tu codes, rédiges, navigues ou gères des fichiers : les mêmes raccourcis fonctionnent partout.

🐢 Sans raccourcis
Sélectionner → clic droit → Copier → naviguer → clic droit → Coller
⚡ Avec raccourcis
Ctrl+C puis Ctrl+V
🔥 Tu n'as pas besoin de tous les mémoriser d'un coup. Commence par les raccourcis d'édition (Ctrl+C/V/Z/A), force-toi à les utiliser une semaine — ils deviendront automatiques.
✏️ Édition universelle
✏️
Ces raccourcis fonctionnent partout

Word, VS Code, navigateur, bloc-notes — ces raccourcis sont universels sur Windows.

Ctrl+C
Copier
Copie la sélection dans le presse-papier
Ctrl+V
Coller
Colle le contenu du presse-papier
Ctrl+X
Couper
Coupe la sélection (copie + supprime)
Ctrl+Z
Annuler
Revient en arrière (Undo) — ton meilleur ami
Ctrl+Y
Rétablir
Refait ce qui vient d'être annulé (Redo)
Ctrl+A
Sélectionner tout
Sélectionne tout le contenu de la zone active
Ctrl+S
Sauvegarder
Enregistre le fichier — à utiliser très souvent !
Ctrl+F
Rechercher un mot
Ouvre la barre de recherche — fonctionne dans Word, le navigateur, VS Code, le bloc-notes…
💡 Ctrl+Z est illimité dans la plupart des logiciels. Si tu fais une erreur, appuie plusieurs fois dessus pour remonter dans le temps.
🖱️ Sélection avancée
🖱️
Sélectionner sans la souris

Ces raccourcis te permettent de sélectionner de grandes quantités de texte rapidement, sans faire de cliqué-glissé imprécis.

Shift+Clic
Sélectionner une plage
Sélectionne tout entre le curseur et l'endroit cliqué
Ctrl+Shift+→
Sélectionner mot par mot
Étend la sélection d'un mot à la fois vers la droite
Shift+↓
Sélectionner ligne par ligne
Étend la sélection vers le bas
Home
Début de ligne
Déplace le curseur au début de la ligne actuelle
End
Fin de ligne
Déplace le curseur à la fin de la ligne actuelle
Ctrl+Home
Début du document
Va tout en haut du fichier
Ctrl+End
Fin du document
Va tout en bas du fichier
📌 Astuce combo : place ton curseur au début d'un texte, puis fais Shift + Clic à la fin — tu sélectionnes tout sans glisser-déposer.
🌐 Navigateur web
🌐
Raccourcis du navigateur (Chrome / Brave / Edge)

Ces raccourcis fonctionnent dans tous les navigateurs modernes basés sur Chromium.

F5
Actualiser la page
Recharge la page depuis le cache du navigateur
Shift+F5
Vider le cache et actualiser
Force le rechargement complet — ignorant tout ce qui est en cache. Alias : Ctrl+Shift+R
Ctrl+T
Nouvel onglet
Ouvre un nouvel onglet vide
Ctrl+W
Fermer l'onglet
Ferme l'onglet actif
Ctrl+Tab
Onglet suivant
Passe à l'onglet suivant (Ctrl+Shift+Tab pour revenir)
Ctrl+L
Barre d'adresse
Sélectionne l'URL — prêt à taper une nouvelle adresse
Ctrl+D
Ajouter aux favoris
Enregistre la page actuelle dans les marque-pages
💡 Pourquoi Shift+F5 plutôt que F5 quand tu codes ?
Quand tu modifies un fichier CSS ou JS et que tu actualises avec F5, le navigateur peut servir l'ancienne version depuis son cache. Shift+F5 force le rechargement complet depuis le serveur — tu vois toujours tes dernières modifications.
💻 VS Code
💻
Raccourcis VS Code — Les essentiels

VS Code affiche les raccourcis directement dans ses menus — survole n'importe quelle option du menu pour voir le raccourci associé. C'est une excellente façon d'en apprendre de nouveaux naturellement.

Ctrl+/
Commenter / décommenter
Met ou enlève le commentaire sur la ligne sélectionnée
Ctrl+H
Rechercher et remplacer
Complète Ctrl+F — cherche un mot ET le remplace par un autre dans tout le fichier d'un coup
Ctrl+Shift+P
Palette de commandes
Accès à toutes les fonctions de VS Code en tapant leur nom
Ctrl+P
Ouvrir un fichier rapidement
Tape le nom du fichier pour l'ouvrir sans naviguer dans les dossiers
Ctrl+`
Terminal intégré
Ouvre/ferme le terminal directement dans VS Code
Alt+↑ / ↓
Déplacer une ligne
Monte ou descend la ligne sans copier/coller
Ctrl+D
Sélectionner la prochaine occurrence
Sélectionne le mot sous le curseur, puis les suivants au fur et à mesure
Ctrl+N
Nouveau fichier
Crée un nouveau fichier non enregistré dans VS Code
🔍 Astuce : dans VS Code, va dans le menu Aide → Référence des raccourcis clavier pour voir la liste complète imprimable de tous les raccourcis disponibles.
🪟 Windows
🪟
Raccourcis système Windows

Ces raccourcis fonctionnent à n'importe quel moment, même hors d'une application.

Alt+F4
Fermer l'application
Ferme la fenêtre ou l'application active
Alt+Tab
Changer d'application
Affiche toutes les fenêtres ouvertes — relâche pour sélectionner
Win+E
Explorateur de fichiers
Ouvre l'explorateur de fichiers Windows
Win+D
Afficher le bureau
Réduit toutes les fenêtres pour voir le bureau
Win+L
Verrouiller l'écran
Verrouille immédiatement la session — pratique quand tu quittes ton poste
Win+V
Historique du presse-papier
Affiche tout ce que tu as copié récemment (activer dans les paramètres)
Print Screen
Capture d'écran
Copie tout l'écran — utilise Win+Shift+S pour une capture partielle
