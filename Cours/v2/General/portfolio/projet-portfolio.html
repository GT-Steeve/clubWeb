🌐 Projet — Mon portfolio en ligne

Planifie, code et héberge un portfolio qui présente tes créations au monde.

HTML/CSS GitHub Pages Portfolio
🎯
Objectif du projet

Un portfolio est ta vitrine professionnelle en ligne. Ce projet consiste à en créer un qui te représente vraiment : tes projets, tes compétences, ton contact.

Il n'a pas besoin d'être parfait — il a besoin d'exister et d'être accessible. Tu l'amélioreras au fur et à mesure que tes projets s'étofferont.

💡 Un portfolio avec 2 projets réels et un design propre est plus efficace qu'un portfolio vide avec un design spectaculaire.
📝
Étape 1 — Définir le contenu

Avant de coder, réponds à ces 3 questions pour savoir quoi mettre dans ton portfolio :

?
Qui suis-je ? — Ton prénom, ta formation actuelle (lycée, BTS, BUT…), ton profil en une phrase.
?
Qu'est-ce que je veux montrer ? — Liste tes 2 à 4 meilleurs projets. Choisit ceux qui fonctionnent vraiment.
?
Comment me contacter ? — Email, GitHub, ou formulaire de contact simple.
⚠️ Ne liste pas les projets inachevés ou qui ne fonctionnent pas. Mieux vaut 2 projets solides que 6 projets dont 4 sont cassés.
🖼️
Étape 2 — Structurer avec un wireframe

Avant de coder, dessine (ou visualise) la structure de ta page. Voici un exemple de structure simple et efficace :

[ HEADER ] Prénom · Titre (ex: "Développeur web junior") Liens : GitHub · Email [ SECTION : À propos ] 2-3 phrases sur qui tu es · Compétences (HTML, CSS, JS…) [ SECTION : Mes projets ] Carte projet 1 → titre · description · lien démo / code Carte projet 2 → … Carte projet 3 → … [ SECTION : Contact ] Email cliquable · Lien GitHub [ FOOTER ] "Fait avec HTML/CSS · © Ton prénom 2025"
💡 Ce wireframe est un point de départ, pas une obligation. Adapte-le à ce qui te représente — ajoute une section compétences, une photo, etc.
💻
Étape 3 — Coder le portfolio

Lance-toi avec une structure HTML simple et construis section par section.

1
Crée index.html et style.css dans un nouveau dossier. Initialise Git.
2
Code le header en premier : ton nom, ton titre, tes liens. Commit quand c'est fait.
3
Ajoute les sections une par une : À propos → Projets → Contact. Un commit par section.
4
Teste sur mobile en réduisant la fenêtre du navigateur. Ajuste avec flex-wrap ou media queries si besoin.
🌍
Étape 4 — Héberger sur GitHub Pages

GitHub Pages est la solution recommandée pour débuter : gratuite, fiable, et ton code est déjà là.

1
Crée un dépôt GitHub nommé portfolio (ou ton-prenom.github.io pour un URL personnalisé).
2
Push ton code : git remote add origin [url] puis git push -u origin main.
3
Dans les Settings du dépôt → Pages → sélectionne la branche main comme source.
4
Attends 1-2 minutes et visite l'URL générée. Partage-la !
🔗 L'URL sera du type https://ton-pseudo.github.io/portfolio/ — copie-la et ajoute-la sur ton profil GitHub et LinkedIn.
✅
Exigences du portfolio v1
✅ Ton prénom et ton profil apparaissent clairement dès le header.
✅ Au moins 2 projets présentés avec titre, description et lien (démo ou code).
✅ Un moyen de te contacter (email ou lien GitHub visible).
✅ Le site est lisible sur mobile (fenêtre réduite à 360px).
✅ Le portfolio est hébergé en ligne et accessible via une URL partageable.
✅ Aucun lien cassé ni image manquante sur la page.
🌟 Un domaine personnalisé (ex : tonprenom.dev) lié à GitHub Pages.
🌟 Une capture d'écran de chaque projet dans les cartes projets.
🌟 Une animation CSS subtile (hover sur les cartes, transition de couleur…).
☑️
Checklist de validation
J'ai défini le contenu (qui je suis, quels projets, comment me contacter)
J'ai esquissé la structure (wireframe mental ou papier)
Le header contient mon prénom et mon profil
Au moins 2 projets sont présentés avec un lien fonctionnel
Mon contact est visible (email ou GitHub)
J'ai testé l'affichage sur mobile
J'ai vérifié tous les liens (aucun cassé)
Le portfolio est en ligne sur GitHub Pages
J'ai partagé l'URL avec au moins une personne
Cours de développement web — Ton portfolio, c'est ta carte de visite ! 🌐
