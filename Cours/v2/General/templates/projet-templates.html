🎨 Projet — Adapter un template

Trouve un template HTML/CSS, comprends-le, et adapte-le pour représenter ton école ou le club journal.

Template HTML/CSS Adaptation Lecture de code Contenu réel
🎯
Objectif du projet

Tu vas trouver un template HTML/CSS sur CodePen, HTML5up, ou un autre site — puis le modifier pour qu'il représente ton établissement scolaire ou le club journal.

Le but principal est de lire et comprendre du code que tu n'as pas écrit, puis de le modifier avec confiance : changer les couleurs, les textes, les images, la navigation, les sections.

🧠 Un dev passe souvent plus de temps à lire du code qu'à en écrire. Savoir comprendre un template inconnu rapidement, c'est une compétence fondamentale.
🏫
Choisir le contexte de ton site

Tu adaptes le template pour l'un de ces deux contextes — choisis celui qui t'inspire le plus :

🏫 L'établissement scolaire
Nom de l'école, sections (accueil, à propos, activités, contact), photos, couleurs de l'école.
📰 Le club journal
Présentation du club, derniers articles, membres de la rédaction, comment rejoindre, archives.
💡 Bons endroits pour trouver un template : CodePen.io (recherche "landing page HTML CSS"), HTML5up.net (templates libres), ou cherche "free HTML template" sur Google. Prends quelque chose de relativement simple.
✏️
Modifications obligatoires

Une fois ton template choisi, tu dois effectuer ces modifications :

1. Textes : Remplace TOUS les textes de placeholder (Lorem ipsum, titres génériques) par le vrai contenu de ton établissement ou club.
2. Couleurs : Adapte la palette de couleurs pour correspondre à l'identité visuelle de l'école ou du club (couleurs officielles si connues, sinon cohérence propre).
3. Navigation : Les liens du <nav> correspondent aux vraies sections de ton site (pas "Home, About, Services, Contact" génériques).
4. Images : Remplace les images de placeholder par des images pertinentes (photos réelles ou libres de droits sur Unsplash, Pexels).
5. Structure : Ajoute ou supprime des sections du template pour que ça corresponde à ce que tu veux présenter — pas obligé de garder tout.
📋
Cahier des charges — Exigences obligatoires
✅ Le template est identifié — note son nom et sa source dans un commentaire HTML en haut du fichier.
✅ Tous les textes placeholder sont remplacés par du vrai contenu lié au contexte choisi.
✅ La palette de couleurs est adaptée — au moins les couleurs principales du template sont changées.
✅ La navigation correspond aux vraies sections du site.
✅ Le site s'ouvre sans erreur — aucun lien cassé, aucune image manquante.
✅ Tu es capable d'expliquer comment 3 éléments du template fonctionnent (une mise en page, un effet, une section).
⭐
Points bonus
🌟 Ajouter une section qui n'était pas dans le template original (créée toi-même en HTML/CSS).
🌟 Ajouter une interaction JavaScript simple : menu hamburger mobile, animation au scroll, modal…
🌟 Publier le site sur GitHub Pages et partager le lien.
🌟 Utiliser des variables CSS (:root { --couleur: … }) pour refactoriser les couleurs du template.
🚀
Comment réaliser ce projet
1
Trouve ton template sur CodePen ou HTML5up. Télécharge-le ou copie le code dans un nouveau dossier local.
2
Lis le code avant de modifier. Ouvre les fichiers HTML et CSS, survole les classes, comprends les grandes sections. Note le nom du template en commentaire.
3
Modifie les textes d'abord — c'est le plus rapide. Remplace tout le contenu placeholder par le vrai texte de ton contexte.
4
Change les couleurs dans le CSS. Cherche les couleurs hexadécimales (ex: #3498db) et remplace-les par ta palette. Utilise Ctrl+H pour chercher/remplacer.
5
Adapte les images. Remplace les src des <img> par tes propres images ou des images libres de droits (Unsplash, Pexels).
6
Ajuste la structure : supprime les sections non pertinentes, ajoute ce qui manque. Teste dans le navigateur après chaque modification importante.
✅
Checklist avant de rendre
✓
Le nom et la source du template sont notés en commentaire en haut du fichier HTML.
✓
Aucun texte "Lorem ipsum" ou placeholder générique ne reste visible.
✓
Les couleurs principales sont adaptées au contexte (établissement ou club journal).
✓
La navigation contient les bonnes sections, pas des labels génériques.
✓
Le site s'ouvre sans erreur dans le navigateur.
✓
Je peux expliquer comment 3 parties du template fonctionnent.
✓
Le résultat représente réellement mon établissement ou mon club journal.
Adapter un template, c'est la réalité du métier. Peu de sites partent de zéro — savoir lire et modifier du code existant est une compétence clé.
